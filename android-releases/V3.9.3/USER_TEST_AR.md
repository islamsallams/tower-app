# تجارب V3.9.3 — ينفذها المستخدم

فحوص الكود المحلية لا تعتبر قبولًا للواجهة أو تشغيلًا أونلاين. تجارب التصفير على بيانات تجريبية مختارة فقط؛ المعاينة لا تحذف.
