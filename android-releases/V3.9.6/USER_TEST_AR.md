# تجربة تصحيح396

1. بعد رفع الويب، حدّث الصفحة وسجل الدخول: تظهر الرئيسية بدل رجوع رسالة تعذر الدخول بعد التحقق.
2. أغلق تطبيق Android وافتحه: تظهر الرئيسية أو شاشة الدخول المعتادة بدل تعذر تشغيل النظام.

لاSQLجديد ولا حاجة لإعادة اختبارات التمويل أو التسويات أو بقية النظام لهذه الدفعة. الاختبار الآلي يثبت إعادة إنتاج خطأ395 تحت مقدمة إعدادات الرفع، ثم نجاح بدء التطبيق وتسجيل الدخول بالتصحيح. لم ينفذ المساعد دخولًا حقيقيًا أو متصفحًا أو هاتفًا.
