# مراجعة تحذير SQL138 — قراءة فقط

الرسالة NOT_RECORDED تعني غياب سجل تنفيذ مطابق لملف138، ولا تثبت غياب أثره عن القاعدة. لا تعِد تشغيل الملف القديم ولا تضع علامة APPLIED لمجرد إخفاء التحذير.

1. افتح ملف AUDIT_138_READ_ONLY.sql وانسخ محتواه بالكامل.
2. افتح Supabase ← SQL Editor ← New query.
3. الصق المحتوى وشغّله، ثم أرسل نتيجة عمود report.

الملف استعلام SELECT واحد على كتالوج القاعدة: تعريفات دوال الحجز وبدء إرسال PDF وفك الحجز وإنهائه وقراءة سجل الترحيلات، وبنية جدول المهام والسجل. لا يقرأ صفوف المستخدمين، ولا ينفّذ دوال التطبيق، ولا يرسل تقريرًا، ولا يغيّر البيانات أو سجل الترحيلات.

التعريفات الحالية قد تثبت وجود السلوك المطلوب الآن؛ وحدها لا تثبت أن ملفًا تاريخيًا بعينه نُفّذ. الكتالوج الحالي في فحص التطبيق يحتوي5 ملفات فقط، ولا يمثل فحصًا شاملًا لكل SQL حتى265. ملخص سلامة النظام المرفق:37 ناجحًا، وصفر أخطاء، و3 لم تُختبر في جلسة الفحص؛ عدم الاختبار لا يعني الفشل أو إلغاء القبول التاريخي لاختبارات أخرى.
