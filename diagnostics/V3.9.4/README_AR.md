# فحص التمويل ورفض العضوية — قراءة فقط

شغّل ملف `READ_ONLY_394_FAILURE_DIAGNOSTIC.sql` كاملًا في محرر SQL داخل Supabase، ثم انسخ خلية `report` الناتجة.

الاستعلام لا ينفذ أي دالة من دوال التطبيق، حتى دالة معاينة التمويل. لا ينشئ أو يعدّل جدولًا أو دالة، ولا يمول مهمة أو يرفض طلبًا أو يرسل إشعارًا.

يفحص وجود الدوال وتوقيعاتها وصلاحياتها، ويقارن جسمي دالتي التمويل والرفض بالنسخة المنشورة، ويعرض بنية الجداول ودوال الحساب المساعدة وأسماء محفزات طلبات العضوية. ويعرض حالات طلبات مجهّلة وإحصاء قرارات الرفض للتحقق من اختلاف الحالة عن السجل.

لا يعرض أسماء الأشخاص أو مبالغهم أو أرقام وحداتهم أو معرفات الطلبات الفعلية أو PIN أو قيم الجلسات أو الأسرار. بصمة الطلب في التقرير قيمة مجهّلة للمقارنة بين النتائج فقط.

هذا استعلام تشخيصي وليس تحديثًا، ولا يحتاج رفع ZIP أو إعادة تشغيل ملفات التثبيت. لا يُعتبر نجاحه إثباتًا لإصلاح التمويل أو رفض العضوية.
