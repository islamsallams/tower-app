# تشخيص مستحقات المهمة لكل وحدة

الحالة: ربط المستحق والمدفوع والمتبقي قيد التحقيق؛ إصدار التطبيق الحالي V2.5.169 لم يتغير.

افتح ملف SQL الموجود في هذا المجلد، وانسخ محتواه كاملًا إلى Supabase SQL Editor وشغّله مرة واحدة. صدّر جدول النتيجة بصيغة CSV وأرسله في المحادثة لاستكمال نفس الدفعة المصرح بها.

الملف يعمل داخل معاملة قراءة فقط، ويقرأ تعريفات الدوال وأعمدة الجداول والقيود والفهارس؛ لا يقرأ سجلات حسابات المستخدمين ولا ينشئ أو يعدل بيانات أو صلاحيات. ترقيم SQL226 هنا للتشخيص فقط، ولا يعني تنفيذ SQL225 أو ترقية قاعدة البيانات.

سبب الاحتياج: قراءة مستحقات المبنى لا تشمل بالضرورة حساب المهمة الشخصية، والقراءة المالية المتاحة تعرض إجماليات الحساب دون تفاصيل المستحق والمدفوع لكل وحدة. لذلك لا يصح استخراج المبلغ من إجمالي المهمة أو تقسيمه تقديريًا.

التحقق المحلي: تحليل الصياغة نجح، واختباران على PostgreSQL محلي بكتالوج اصطناعي نجحا، مع التأكد من بقاء سجلات الاختبار كما هي. لم يُنفذ هذا الملف على Supabase المنشور بعد. اختبارات الدورة المالية السبعة ما زالت مؤجلة.
