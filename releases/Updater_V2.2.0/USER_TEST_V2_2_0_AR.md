# تجارب Updater V2.2.0

فك الحزمة وشغّل Tower Supabase Updater.vbs من المجلد الجديد. اختبارات الشاشة على المستخدم؛ الاختيار والاستيراد لا يرفعان شيئًا.

| التجربة | تعمل إيه؟ | النتيجة المطلوبة |
|---|---|---|
| مكان النافذة | اقفل البرنامج وافتحه، وكرر على الشاشة الثانية لو عندك | النافذة في وسط مساحة الشاشة الحالية، دون شريط المهام |
| اختيار يدوي | اضغط الكارت واختَر حزمة التطبيق | الإصدار كبير وواضح، والاسم والحجم أسفله، والملف جاهز فقط |
| السحب | اسحب حزمة التطبيق إلى النافذة | نفس نتيجة الاختيار اليدوي؛ لو دعم السحب ناقص، الـLauncher يحاول تثبيته كما في النسخة السابقة |
| حفظ المجلد | اختر مجلد التنزيلات من Folder، ثم أعد فتح البرنامج | المجلد محفوظ ويظهر مساره في Settings > General |
| الاستيراد | ضع أكثر من إصدار وملف SOURCE داخل المجلد واضغط Auto Import | أعلى إصدار متوافق يجهز تلقائيًا، ولا يبدأ الرفع |
| نفس الإصدار | اختَر إصدار التطبيق الحالي | تنبيه أزرق بأيقونة معلومات، وزر التحديث متاح |
| إصدار أقدم | اختَر إصدارًا أقدم صالحًا | تحذير برتقالي وأيقونة تحذير، مع الإصدارين، وزر التحديث متاح |
| فحص الحزمة | اختَر ZIP غير متوافق | خطأ منظم بالعربي، دون بدء التحديث، وأزرار الخطأ والـLog متاحة |
| الرفع | عند تحديثك القادم اضغط Update Project | المراحل والوقت ظاهران والحركة مستمرة؛ اختيار الملف والإعدادات مقفلان أثناء العملية |
| نتيجة الرفع | راجع النتيجة أو الخطأ إن حدث | المراحل المكتملة واضحة، والتحقق المنتظر لا يطلب إعادة رفع تلقائية |
| الهاتف | اضغط رقم التليفون في التذييل | يتم نسخ01095851719 دون Contact: |
| الشاشات الصغيرة | جرّب النافذة على شاشة لابتوب أو DPI مختلف | الكارت وزر التحديث والـLoader والتذييل واضحون؛ راجع المساحات عندك |

لم تُجر تجربة GUI أو Drag and drop فعلية أو رفع Cloudflare أو Supabase أثناء التجهيز.
