# التحقق المحلي — Updater V2.2.0

نجح39 اختبار كود عبر Python بدون إنشاء نافذة Tk أو تشغيل متصفح. الاختبارات تغطي ترتيب الإصدارات والمقارنة غير المانعة، وحساب التوسيط بما فيه شاشة بإحداثيات سالبة، واختيار أحدث ZIP وتجاهل التالف والمصدر، وفحص CRC والمسارات وWorker، وحفظ المجلد وفشل حفظه، واختيار ملف أثناء فحص السابق، ومنع استبدال الحزمة أثناء الرفع، وتنقيح السجلات.

اختبارات تتابع المراحل تستخدم بدائل محلية للرفع والخادم: النجاح، وفشل النسخ، وفشل Cloudflare بعد النسخ، وفشل Supabase بعد نجاح Cloudflare، والتحقق المنتظر، والرجوع لإصدار أقدم. اختُبر محرك النسخ المحلي الحقيقي داخل مجلد مؤقت، وتحضير Worker الحقيقي دون نشر أو طلب KV، مع التأكد من عدم قراءة قيم Tk من مسار الخلفية وبقاء Cron وkeep_vars وعدم نشر Worker كملف عام.

نجحت ملفات الفحص القديمة216 و217 و218 و219. تغيير اختبار219 الوحيد هو توقع رقم Updater الجديد. نجحت23 مقارنة حفظ، تشمل الدوال الأصلية لفحص وفك ZIP وتجهيز Worker وKV وCron وفحص الحزمة وتجهيز النسخ الاحتياطي؛ محرك backup_tools والـLauncher والأيقونات محفوظة. تغيير عرض تحذيرات النسخ الاحتياطي لم يغيّر مساره.

فحص بناء ملفات Python نجح. لم يُبنَ EXE لويندوز، ولم تُفتح الواجهة، ولم تُختبر Windows APIs أو DPI أو السحب فعليًا. لم تُستخدم بيانات دخول أو تُرسل طلبات نشر أو تتغير قاعدة بيانات. قبول الشاشة والتشغيل على Windows والأونلاين للمستخدم دائمًا.
