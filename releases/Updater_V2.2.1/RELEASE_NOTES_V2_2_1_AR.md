# إصدار Updater V2.2.1 — تحديث تلقائي بضغطة واحدة

- الزر الرئيسي «Auto Update» أزرق وبارز في منتصف النافذة. يختار أحدث ZIP تشغيل متوافق من الفولدر المحفوظ، يفحصه، ثم يبدأ نفس مراحل التحديث الحالي بالضغطة نفسها.
- أول استخدام دون فولدر يطلب اختياره، ثم يكمل بنفس الضغطة عند حفظ الاختيار. الإلغاء أو فشل حفظ الفولدر لا يبدأ رفعًا. زر Folder يغير الفولدر فقط ولا يبدأ تحديثًا.
- زر «Manual Update» عادي داخل كارت اختيار ZIP. الضغط على الكارت والسحب والإفلات يجهزان الملف فقط، ثم يبدأ تحديثه يدويًا بهذا الزر؛ لا تتحول هذه الطرق إلى رفع تلقائي.
- أثناء فحص الحزمة أو التحديث يمنع تكرار Auto Update أو فتح اختيار ملف/إفلات ملف آخر. استجابة فحص قديمة أو ملغاة لا تبدأ تحديثًا. فشل الاستيراد لا يعيد استخدام ملف مختار سابقًا ولا يعيد المحاولة تلقائيًا.
- نفس الإصدار أو الأقدم يظل تنبيهًا ملونًا بلا منع أو تأكيد إضافي؛ الرجوع لإصدار أقدم متاح من Manual Update. عند استخدام Auto Update يختار أعلى إصدار متوافق في الفولدر، لا آخر ملف تم تنزيله فقط.
- مسار تحديث الملفات وCloudflareودوالSupabaseوالتحقق الأونلاين والـLoaderومراحل التقدم والنسخ الاحتياطي والإعدادات ونسخ الأخطاء والـLogوالتوقيع ورقم التليفون محفوظة. موضع الـLoader مرتبط بحاوية الزر الرئيسي الجديدة، دون وضعه داخل كارت التحديث اليدوي.
- لا تحديث عند تشغيل البرنامج أو استرجاع الفولدر أو تغييره. لا تغييرات لتطبيق Tower Appأوحساباته أو أيSQL.

## التشغيل

فك ZIP الـUpdater في مجلد جديد، وشغّل Tower Supabase Updater.vbs. لا ترفعه من داخل Updater باعتباره تحديثًا للتطبيق. هذه حزمةPythonمعLauncherمثل السابقة؛ لاEXEمبني علىLinux.

الإعدادات المحفوظة للفولدر والمشروع كما هي. لو تستخدم اختصارًا قديمًا افتح النسخة الجديدة أولًا ثم ثبّت اختصارها من Settings → Diagnostics → Install in Start Menu.
