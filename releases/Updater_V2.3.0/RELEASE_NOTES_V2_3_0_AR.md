# إصدار Updater V2.3.0 — نافذة عائمة مصغّرة

## التشغيل

فك حزمة Updater الجديدة في مجلد جديد، وشغّل **Tower Supabase Updater.vbs**. زر **Mini** في الهيدر يفتح الوضع العائم؛ تصغير النافذة الكاملة من شريط عنوان Windows يفتحه أيضًا. **لا ترفع ZIP الـUpdater كأنه ZIP تطبيق Tower App، ولا يوجد SQL جديد.**

## الوضع المصغّر

- كارت مضغوط بألوان الـUpdater، يظهر فوق البرامج افتراضيًا. اسحب شريط عنوانه إلى المكان المطلوب؛ يحفظ مكانه واختيار Top في نفس ملف إعدادات المستخدم، دون تغيير إعدادات المشروع أو الاتصالات.
- زر **● Top / ○ Top** يثبّت أو يلغي الظهور فوق البرامج. **↗** أو **التفاصيل والـLog** يعيد النافذة الكاملة؛ النقر المزدوج على العنوان أو Escape يفعل الشيء نفسه.
- زر **—** داخل الكارت يتيح التصغير العادي لشريط مهام Windows، دون العودة التلقائية للكارت في حلقة. عند استعادة البرنامج من شريط المهام تظهر النافذة الكاملة. لا زر خروج يقطع عملية التحديث من داخل الكارت؛ الإغلاق النهائي من النافذة الكاملة وبشروطه السابقة.
- **NEW / LOCAL / ONLINE** تستخدم نفس متغيرات الإصدارات في النافذة الكاملة، فتتحدث بعد الفحص والتحديث والتحقق. NEW هو الإصدار المختار/المفحوص كما في الواجهة الكاملة؛ لا فحص خلفي جديد للفولدر بمجرد فتح الكارت. Auto Update نفسه يختار أحدث حزمة متوافقة عند ضغطه كما في V2.2.1.
- **Auto Update** يستدعي نفس نقطة الدخول الحالية. يُمنع تكرار الضغط أثناء الاختيار أو التحديث أو النسخ الاحتياطي، ويظهر Loader بسيط والمرحلة الفعلية والوقت أثناء التحديث؛ لا نسبة مئوية مصطنعة.
- عند النجاح تظهر علامة نجاح؛ عند الفشل تعرض النافذة الكاملة نفس التفاصيل والأزرار القابلة للنسخ والـLog. لو أعدت فتح الكارت بعد فشل فزر Retry Update يبدأ فقط بضغطة صريحة جديدة. حالة التحقق المعلّق تُعرض منفصلة، ولا يشجع زر الكارت على إعادة الرفع؛ افتح التفاصيل.
- لو لم يُحفظ فولدر حزم بعد، تعود النافذة الكاملة قبل اختيار الفولدر بنفس Auto Update الأصلي. نافذة إعدادات أو حوار مفتوح يحتفظ بظهوره بدل إخفائه خلف الكارت.
- رجوع العرضين لا ينشئ وظيفة أو تحديثًا ثانيًا. الكارت لا يشغّل تحديثًا تلقائيًا بمجرد فتحه أو تحريكه. يُفتح البرنامج كاملًا عند تشغيله؛ مكان الكارت وTop محفوظان عند فتحه لاحقًا.
- عند فصل شاشة أو تغيّر مساحة العمل، يعاد موضع الكارت إلى حدود شاشة متاحة. مواضع الشاشات يسار/أعلى الرئيسية تستخدم إحداثيات Win32 المطلقة. حجم الكارت يستوعب المقاس المطلوب للخط ضمن مساحة العمل المتاحة.

مسارات تحديث التطبيق والرفع وSupabase والتحقق وحفظ الإعدادات والنسخ الاحتياطي وManual Update كما هي. تعديل تثبيت Start Menu يضم ملف الوضع المصغّر الجديد إلى النسخة المنسوخة. Build_EXE يعتمد الاستيراد الصريح للوحدة الجديدة؛ **لم تُبنَ نسخة EXE أو تُختبر واجهة Windows في هذه البيئة**. الحزمة مصدر Python مع Launcher مثل السابقة، وكل المصدر بداخلها.

## التحقق

نجحت74تجربة كود محلية بلا Tk root أو نافذة فعلية:21للوضع المصغّر و53من النسختين السابقتين. تشمل المنع من التكرار، مشاركة الإصدارات وحالة التقدم، اختيار الفولدر، التثبيت والموضع والتصغير الطبيعي والرجوع للأخطاء، والحدود والإحداثيات السالبة. فُحص تطابق محركات التحديث السابقة بالدوال، وحفظ الملفات التاريخية في الحزمة. هذه الفحوص ليست قبولًا بصريًا أو اختبارًا لتعامل Windows الفعلي مع التركيز والتصغير أو لشاشات متعددة.

لا نشر Cloudflare أو Supabase أو اختبار حي أو كتابة قاعدة بيانات أو تشغيل تحديث حقيقي بواسطة المساعد. تجارب Windows والتحديث الحقيقي للمستخدم. تطبيق Tower App وSQL والتقارير وPDF لم تتغير.
