# إصدار V2.5.170

كارت مهمة الساكن وتفاصيلها يعرضان المستحق المعتمد والمدفوع المخصص للمستحق والمتبقي للوحدة النشطة، من دفتر المستحقات الفعلي بدل الإحالة إلى دفتر العمارة. العرض في صفحتي الوحدة والخدمات يستخدم نفس الدالة. الحساب بالقروش، والعرض يتبع الاتفاق الحالي بتقريب الجنيه لأعلى.

القراءة تستبعد المستحق الملغى والإيصال المعكوس والمقدم غير المخصص ومساهمة الصندوق. عند فشل القراءة تظهر رسالة عدم إتاحة؛ غياب المستحق المسجل له رسالة مستقلة، ولا يستبدل بصفر أو نصيب تقديري أو إجمالي حساب المهمة.

## ترتيب التشغيل

1. شغّل SQL227 الموجود كملف مستقل في Supabase SQL Editor؛ يضيف دالة قراءة فقط وصلاحية تنفيذ للـWorker، ولا يغير بيانات مالية أو دوال قائمة.
2. ارفع Tower_App_V2.5.170.zip بطريقتك المعتادة. احتفظ بملف SOURCE منفصلًا.
3. أبلغني بإتمام الخطوتين لاستكمال الاختبار الأونلاين بنفس الدفعة دون نقطة جديدة.

إذا رُفع التطبيق قبل SQL، تظل الخدمات قابلة للعرض، وتظهر الأرقام كغير متاحة لحين تثبيت الدالة. لا تعتبر الاختبارات المحلية قبولًا للنسخة المنشورة. لا تغييرات في المشاوير، والاختبارات المالية السبعة مؤجلة.
