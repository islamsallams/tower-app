# التحقق المنشور — نافذة تعديل الوحدة للأدمن

الإصدار المنشور V2.5.171. نُفذت24 نقطة تحقق ناجحة في Chromium على عرضي1366 و390، باستجابات النظام المنشور وSupabase الفعلية، دون محاكاة API.

عُدل حقل الدور داخل النموذج فقط دون حفظ. جُربت محاولات الإغلاق عبر X والإلغاء وEscape وخلفية النافذة وزر الرجوع. في كل حالة ظهر تحذير التعديلات غير المحفوظة، ورفض التجاهل أبقى النافذة والقيمة المعدلة. قبول التجاهل أغلق النافذة. أعيدت قراءة قائمة الوحدات من الخادم، وطابق سجل الوحدة الأصلي بالكامل على كلا العرضين.

لم يُحفظ أي تعديل ولم تُغير بيانات أو صلاحيات أو قيود مالية. لم تُفتح صفحات المشاوير. لا تعديل للكود ولا إصدار أو ZIP أو SQL جديد نتيجة هذه الدفعة.

القبول يخص مسارات ترك نافذة تعديل الوحدة المذكورة فقط. لا يشمل نجاح الحفظ، أو تغيير المدير، أو كل نماذج النظام أو الأدوار الأخرى. بنود49–52 تقبل جزئيًا لهذا النموذج، وتبقى بقية النماذج ومساراتها مفتوحة. الاختبارات المالية السبعة مؤجلة كما هي. الأدلة التفصيلية محفوظة خارج Git/SOURCE دون نشر أسماء أو بيانات دخول.
