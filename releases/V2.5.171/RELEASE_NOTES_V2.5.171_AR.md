# إصدار V2.5.171

بعد تثبيت SQL227 ونشر170، اختُبرت قراءة دفتر المهمة فعليًا بحساب الساكن: فصل الوحدات، الكارت والتفاصيل، الموبايل والديسكتوب وإعادة الفتح. ظهر عنوان تفاصيل المهمة بدون رقم الوحدة، رغم وصول الأرقام المالية للوحدة الصحيحة.

الإصلاح: عنوان التفاصيل يقرأ رقم الوحدة من اختيار الوحدة النشطة، بدل بيانات Home التي لا تحمل الرقم أو قد تخص وحدة سابقة. لا تعديل على احتساب المستحقات أو SQL أو المشاوير.

ارفع ZIP التشغيل171 فقط بالطريقة المعتادة. SOURCE منفصل للرجوع للكود والاختبارات والـBacklog. SQL227 المثبتة تظل كما هي؛ لا تحتاج إعادة تشغيلها، ولا يوجد SQL جديد. بعد الرفع أبلغني لاستكمال فحص العنوان على النسخة المنشورة بنفس الدفعة.
