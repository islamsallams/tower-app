# إصدار V2.5.176 — إصلاح تحميل تفاصيل الخدمة

عند فتح خدمة في175 كانت دالة تحميل الصفحات تعرض النسخة المحفوظة من صفحة الخدمات داخل النافذة لحظةً، ثم تستبدلها بالتفاصيل. أزيل استعمال دالة تحميل الصفحات من هذا المسار، واستعملت النافذة نفسها بعنوان الخدمة ومؤشر تحميل محلي من المكونات القائمة؛ لا نسخ لقائمة الخدمات إلى النافذة ولا CSS جديد.

الحماية من الردود المتأخرة وإعادة الفتح بعد الإغلاق وتبديل الحساب/الوحدة محفوظة. لا تعديل لحسابات أو خطوات مالية أو دوال مشاوير. تغييرWorker لختم الإصدار فقط، وملفاتSQL السابقة محفوظة دون تغيير.

التركيب: ارفعZIP176 بالـUpdater بدل175. لاSQL جديد ولا إعادة تشغيلSQL232 إن كانت مثبتة مع175. SOURCE منفصل وكامل، وكل مسارات مصدر175 والـBacklog محفوظة.

اختبارات كود سريعة فقط: أعيد إنتاج المشكلة بعقد يضع محتوى صفحة محفوظة، ثم نجح بعد الإصلاح ضمن22 حالة نموذجNode. نجحت18 ملفات اختبار مصدر، وفحص الصياغة والتطابق، وعقودWorker التي يشغلها سكربت المصدر. لا متصفح أو صور أو دورات مالية أوSQL أو اختبار أونلاين في هذه الجولة. اختبار الشاشة للمستخدم حسب الاتفاق، ولم يُنشر التطبيق من طرف المساعد.
