# إصدار V2.5.178 — تنظيم التحصيل عند الاتحاد والحارس

صفحة واحدة بنفس مكونات ولغة تصميم المهمات والخدمات، بدل قائمة مستحقات الخدمات والمهمات فوق صفحة التحصيل القديمة. المستحقات مجمعة حسب الوحدة، والحسابات تظل منفصلة في القيود.

## تنظيم الصفحة

- تبويبات التحصيل والاعتمادات والتقارير؛ الاعتمادات للإدارة والاتحاد. الحارس يرى التحصيل وتقاريره. الإدارة تراجع دون إتاحة تسجيل تحصيل لها.
- بحث بالوحدة والدور والمدير بلقبه أو اسم الخدمة، وفلاتر الدور ونوع المستحق أو حساب خدمة محدد والترتيب. كارت مختصر لكل وحدة، وتفاصيل البنود والسداد الكامل أو الجزئي عند فتحه.
- تحديد الظاهر وإلغاء تحديد الظاهر ومسح التحديد، مع الاحتفاظ بالتحديد عبر الفلاتر وإظهار البنود المحددة خارج الفلتر. اختيار الوحدة يشمل البنود الظاهرة المتاحة فقط. الحساب أو الوحدة الموقوفان لا يضافان للتحصيل.
- شريط مراجعة ثابت أثناء التحديد يعرض عدد الوحدات والبنود والإجمالي، ويمنع التأكيد عند مبلغ غير صالح أو متبقٍ تغيّر أو تجاوز100 بند.
- مراجعة واحدة توضح الوحدة وجهة كل مبلغ. المبالغ المعروضة لأعلى جنيه، والإدخال والطلب يحتفظان بالقروش. طريقة السداد تخص الصندوق؛ الخدمات تستخدم مسار الحساب الشخصي القائم.
- تقرير الصندوق ومراجعة سطوره أعيد تنسيقهما؛ الاعتماد أو الرفض الجماعي للسطور اختيار داخل المراجعة فقط، ولا ينفذ قبل التأكيد النهائي. النسخ والطباعة والمشاركة محفوظة.
- سجل للعمليات المجمعة، مع تحميل العمليات الأقدم وتفاصيل الوحدة والحساب، والنسخ والطباعة والمشاركة. تقارير الصندوق السابقة موجودة، ولا يتكرر تقرير الصندوق داخل القائمة عند ظهوره ضمن عملية مجمعة.

## قواعد الحفظ

إضافةSQL233 تضع حدود معاملة واحدة حول دوال الصندوق والخدمات الحالية. لا إعادة كتابة لمحركات التحصيل الأصلية، ولا تفعيل لمسارMixed التجريبي القديم المحمي بإعداداته.

- الاتحاد: الصندوق يسجل ويعتمد بالدالة القائمة؛ الخدمات والمهمات تسجل على حساباتها وفي عهدته.
- الحارس: الصندوق ينشأ في تقرير مرسل للاعتماد؛ تحصيل الخدمات يسجل على حساباتها وفي عهدته وفق سلوك230 القائم. المراجعة توضح الفرق قبل التأكيد.
- لو فشل بند، ترجع كل الكتابات المالية داخل العملية؛ لا يسجل جزء ويترك جزءًا. الرفض له نتيجة محفوظة بمبالغ صفر، دون الاحتفاظ بأي كتابة مالية جزئية.
- مرجع ثابت لكل مراجعة يمنع تكرارها عند إعادة الطلب. لو النتيجة غير مؤكدة بسبب الاتصال، تحفظ المراجعة في جلسة نفس الحساب ويقف تعديلها حتى التحقق أو إعادة نفس الطلب. الرجوع للصفحة يستعلم عن الحالة فقط ولا يسجل تحصيلًا تلقائيًا.
- مبلغ الحارس للصندوق في سجل العملية هو المبلّغ، لا يفترض اعتماده كاملًا. نتيجة الاعتماد الفعلية تراجع من تقرير الصندوق. الخدمات تظل مستقلة عن الصندوق.
