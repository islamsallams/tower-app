# إصدار V2.5.181 — مسؤول المهمة وصلاحيات الإدارة والأقساط

- صلاحيات الأدمن والاتحاد متساوية في الخدمات والمهمات، بما فيها التحصيل الشخصي والاعتمادات والإلغاء بعد التسوية عند استيفاء شروطه. لا تغيير لصلاحيات الإدارة العامة أو التحصيل المختلط لصندوق العمارة أو أعلام تشغيل المحاسبة التجريبية.
- مسؤول المهمة يستطيع إدارة المشتركين وطلبات الانضمام قبل الإغلاق، ومعاينة التوزيع، وتحديث مرحلة التنفيذ والإنجاز، وتسجيل مصروف ومسودة تسوية والتحصيل لمهمته فقط. مدخل «مسؤولياتي» يظهر للحساب المكلّف، سواء ساكنًا أو حارسًا أو إدارة، دون تغيير دوره العام أو فتح بيانات مهمات أخرى.
- اعتماد التوزيع والمصروف والتسوية والصندوق والإلغاء النهائي وتغيير المسؤول للأدمن والاتحاد. المسؤول يستطيع إرسال طلب موثق للتوزيع أو التكلفة أو الإلغاء؛ مراجعة الطلب لا تنفذ عملية مالية تلقائيًا، بل تستخدم الإدارة الإجراء القائم.
- تغيير المسؤول يسحب صلاحية السابق عند الطلب التالي. العهدة والتحصيل السابقان يظلان لصاحب الاستلام الفعلي. مصروف عهدة المهمة الذي سجله المسؤول ثم اعتمدته الإدارة ينتظر تأكيد الصرف من صاحب العهدة؛ لا يخصم من عهدة الشخص الذي اعتمد.
- الأقساط الجديدة بزر واحد «حفظ»: العدد والجدول يحفظان في معاملة واحدة. أول قسط يوم1 من الشهر التالي بتوقيت القاهرة، دون موعد يدوي. فشل إنشاء الجدول يرجع تعديل العدد والموعد معه. الجداول المثبتة لا يعاد توزيعها أو تغيير قيودها ومدفوعاتها؛ اختلاف العدد فيها يحتاج معالجة منفصلة ولا يسمح الحفظ الحالي بإعادة كتابتها.
- جدول السداد سطر واحد لكل وحدة: رقم الوحدة والدور ومديرها بلقبه، نسبة السداد والمتبقي. تفاصيل الأقساط عند الطلب. الحساب بالقروش والعرض لأعلى جنيه؛ نقص الدفتر لا يتحول إلى صفر مفترض.
- إلغاء ربط منظومة المشاوير بالمهمات نهائيًا، والمصروف اليدوي كافٍ. مراجعة الاتفاقات القديمة مرفقة مستقلًا مع الجرد الأصلي112 بندًا وإضافاته، وحالات الإثبات والقبول غير المكتمل.

## التثبيت

شغّل ملفSQL236 المستقل بعدSQL235 المثبت، ثم ارفعZIP تشغيلV2.5.181 عبرUpdater. رفعZIP لا يشغّلSQL. ملفSOURCEV2.5.181 منفصل للحفظ والتطوير. تشغيلSQL236 لا ينشئ أقساطًا أو مستحقات أو يحوّل حسابات قديمة تلقائيًا.

## التحقق

نجح57 فحصًا محليًا جديدًا:26 SQL و13 نموذج كود و18 Worker، ومعها93 فحص رجوع و18 ملف اختبار مصدر. نجح التحضير المحلي بحزمةUpdater؛ لا نشر أو تشغيلSQL أونلاين أو متصفح في هذه الدفعة. الشاشة والتشغيل المنشور للمستخدم دائمًا.
