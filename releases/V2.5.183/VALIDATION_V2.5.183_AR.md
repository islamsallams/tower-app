# تقرير تحقق V2.5.183

## الاختبارات الجديدة

- فحوص SQL239 عددها14: استكمال SQL238 بعد فشل تثبيته، مع بقاء حجب حساب الوحدة وإتاحة الصندوق العام؛ إنشاء المهمة وشروطها معًا، والتكرار ومنع اختلاف نفس المرجع، ورفض الوحدات أو المواعيد غير الصحيحة، ورجوع الحساب والخدمة والمشروع عند فشل حفظ الشروط بعد الإنشاء. واختبار الدورين والرفض للأدوار الأخرى، وسجل صندوق48 حركة بصفحات12 دون تداخل، والبحث العربي وخارج آخر الحركات، والوارد والمنصرف والملغى، وحدود اليوم بتوقيت القاهرة، والنتائج الفارغة وتصحيح رقم الصفحة، ورفض الفلاتر غير الصحيحة دون تغيير السجل، وإعادة تطبيق الملف وصلاحيات الدوال.
- نموذج Node عدد فحوصه18: التقسيم والبحث قبل التقسيم وفلتر الحالات والمسندة لي والطلبات، والأزرار الأربعة والعدادات، واستقلال حالة الحساب، وعدم تركيب أكثر من12 كارت في الصفحة، وحركة الصندوق دون شارة وبمرجع قابل للفتح وهروب النصوص، وملخص4 حركات، ومعلمات طلب السجل ورفض الردود القديمة وحفظ الفلاتر عند الفشل. وكذلك أربع تبويبات بترتيب فعلي فوق المحتوى، ودمج تعديل التكلفة، ومسؤولياتي بصفحات، وإعدادات إنشاء مغلقة افتراضيًا، ومنع الحفظ دون وحدات مختارة، وطلب إنشاء واحد، وعدم وصول استجابة الوحدات لنافذة جديدة. هذه اختبارات سلاسل وكائنات صغيرة؛ لا DOM أو متصفح أو تشغيل شاشة.
- عقود Worker عبر HTTP محلي عددها8: نفس تصفح الصندوق للدورين عبر RPC محدود ومعلمات الجلسة والفلاتر، ورفض الساكن والحارس، وطلب إنشاء واحد يشمل الشروط، ورفض PIN المؤقت، ورسالة عربية لخطأ الفلتر.

## فحوص الرجوع

نجح168 فحصًا: مسؤولية المهمة SQL26 بعد تركيب SQL239، ونموذجها13 وWorker18، ونموذج الخدمة22 والتحصيل26 والمبالغ11 والوحدة14، وفحوص SQL238 عدد14 ونموذج182 عدد14 وWorker182 عدد10. نجحت18 ملفات مصدر، وعقود سياق الخدمة وملاحظات الحارس وصياغة JavaScript والمرايا.

توقع قديم في اختبار المصدر كان يفرض تركيب جميع الكروت ثم إخفاء غير المختار؛ استبدل بتوقع توصيل الكروت بالصفحة المحدودة، مع نموذج سلوكي يغطي25 عنصرًا وعدم فقدها. سياق اختبار182 أضيفت له تبعية البحث التي يستخدمها مكوّن المسؤوليات الجديد، دون إسقاط تحقق قديم. النسخ الأصلية لنتائج الإصدارات السابقة محفوظة فيSOURCE، ونتائج الرجوع الحالية فيqa/v2.5.183.

المقارنة تثبت تطابق58 تصريح دالة للمشاوير والتسويات مع182، وثبات حقوق النشر وكل SQL سابق بايتًا مقارنة بمصدر182 المصحح. حزمة التشغيل5 ملفات، وكل مسارات المصدر السابق محفوظة. تحضير Updater محلي7 فحوص دون قراءة أسراره أو نشر. بصمات وCRC ومرايا الحزم فيdelivery-checks.

## حدود الإثبات

بيئة PGlite محلية بمخطط اصطناعي مشتق من metadata ومحركات المشروع السابقة الحقيقية. اختبارات إنشاء المهمة تستخدم المحرك الأصلي ونفس معاملة التراجع، لا بديلًا لحساباتها. جدول الصندوق محلي مع أعمدة اختبار إضافية، ويغطي48 حركة اصطناعية وإثبات عدم إرجاع العمود الخاص من الإسقاط العام. ليست هذه عينة أو مطابقة لبيانات Supabase المنشورة.

اختبار استكمال238 يستخدم بدائل صغيرة للقارئين القديمين وتجميع الصندوق، ومقطع بوابة الصندوق وفرع undo المرسلين من المستخدم، دون قيود جداول الإنتاج غير المرسلة. التعريفات تحافظ على Windows CRLF والمسافات واختلاف BEGIN لاختبار التصحيح. علامة اعتماد234 غير مستدعاة وجدول إشعارات اصطناعي مطلوبان لبعض المحركات؛ لا قناة إرسال أو إشعارات فعلية.

لا اختبار حمل أو اتصالات قاعدة مستقلة متزامنة. لا متصفح أو صور أو شاشة أو أونلاين أو نشر تطبيق أو كتابة مالية. عدم تكرار الكتابة واختلاف الاستجابات اختبرا محليًا فقط. الملف الجديد يستكمل238 عند غياب دالته الدالة على التثبيت؛ لا يدعي إصلاح كل تركيب يدوي جزئي أو تعديل خارجي غير معروف.

الألوان والثيمان والموبايل ولوحة المفاتيح والطباعة والتشغيل الفعلي للمستخدم. لا قبول بصري تلقائي، ولا إغلاق شامل للجرد أو المالية السبعة: ستة نجحوا أونلاين174 والسابع، منع البدء قبل تحقق التحصيل، إصلاحه محلي حتى تأكيد منشور جديد.
