# إصدار V2.5.187 — إصلاح قائمة المزيد

اختيار صفحة من «المزيد» كان يغلق القائمة بأمر رجوع غير متزامن ثم يفتح الصفحة؛ وصول الرجوع بعد الفتح كان يعيد الصفحة السابقة. أصبح الاختيار يغلق القائمة ويستبدل مدخلها في سجل التنقل بالصفحة المطلوبة، دون إرسال أمر رجوع متأخر.

التحقق من صلاحيات الصفحة والدور مستمر، والضغط المكرر بعد إغلاق القائمة لا ينفذ انتقالًا جديدًا. إغلاق النوافذ العادية وزر الرجوع كما هما. لا تعديل على شاشات المشاوير أو الحسابات أو CSS أو SQL.

ارفع حزمة التشغيل187 فقط؛ لاSQL جديد. تجربة الشاشة والأونلاين للمستخدم.
