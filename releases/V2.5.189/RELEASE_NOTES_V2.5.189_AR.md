# إصدار V2.5.189 — تنظيم صفحات الساكن

الرئيسية أصبحت ملخصًا مدمجًا لاستحقاقات العمارة وحساب الحارس، مع اختصارات للخدمات والمهمات وأعضاء الوحدة، وآخر الاستحقاقات وملخص صندوق أصغر. أزرار المشوار والحساب موجودة، والتسوية والمسافات داخل «إجراءات» عند إتاحتهما سابقًا؛ صفحات المشاوير وحساباتها لم تتغير.

صفحة العمارة أصبحت تبويبين بالأعلى: «حساب الوحدة» و«صندوق العمارة»، باستخدام نفس المسارات السابقة كي تستمر الروابط والرجوع. الحساب الخاص يظهر محجوبًا عند منعه، ويظل الصندوق العام متاحًا من التبويب. كارت الاستحقاق يعرض المتبقي بجانب البند قبل فتح التفاصيل، والتواريخ بصيغة موحدة.

كارت المهمة يعرض المستحق المسجل مرة واحدة مع المدفوع والمتبقي. حالة المشاركة وشارة التوزيع لا تكرران نفس العبارة؛ وغير المشارك لا يظهر له مبلغ شخصي بشرطة. الطلبات والتقديرات والخصوصية محفوظة.

نطاق الأرقام واضح: ملخص استحقاقات العمارة يقرأ دفتر تحصيلات العمارة، ومتبقي المهمة يقرأ دفتر المهمة. لم يُجمع الرقمان أو تتغير قيود مالية. الخدمات والمهمات لها اختصار مباشر من الحساب إلى تبويبها في الوحدة.

حماية النتائج المتأخرة تراعي الحساب والجلسة والوحدة والصفحة وطلب العرض الحالي، فلا ترسم بيانات قديمة بعد تبديل الوحدة أو الرجوع. لا SQL جديد. اختبار الشاشة والموبايل والأونلاين للمستخدم دائمًا.
