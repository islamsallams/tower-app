# تجارب الإصدار V2.5.189

ارفع حزمة189 وحدّث التطبيق. لا SQL جديد.

| التجربة | تعمل إيه؟ | النتيجة المطلوبة |
|---|---|---|
| الرئيسية | افتح حساب ساكن من الكمبيوتر والموبايل | ملخص أصغر للحسابين واختصارات واضحة، والصندوق في كارت مدمج |
| نطاق المبلغ | قارن استحقاقات العمارة بمتبقي المهمة | كل مبلغ يحمل وصفه؛ لا جمع تلقائي بين الحسابين |
| الحساب والصندوق | افتح العمارة وتنقل بين حساب الوحدة وصندوق العمارة، ثم اضغط رجوع | التبويبان بالأعلى والرجوع يعيد المسار السابق |
| مبلغ الاستحقاق | افتح حساب الوحدة قبل فرد بند المياه أو غيره | المتبقي ظاهر على الكارت، والتفاصيل تعرض المستحق والمدفوع |
| كارت المهمة | افتح الوحدة ثم المهمات | المستحق مرة واحدة، وبجواره المدفوع والمتبقي؛ الحالة دون تكرار |
| عدم الاشتراك | راجع مهمة توزيعها معتمد ولم تشترك فيها | لا مبلغ شخصي بشرطة، ولا زر طلب اشتراك بعد الاعتماد |
| الطلبات | راجع مهمة مفتوحة وطلبًا معلقًا إن وُجد | طلب الاشتراك ومتابعته كما كانا |
| الاختصار | اضغط الخدمات والمهمات من الرئيسية أو حساب الوحدة | تفتح الوحدة على تبويب الخدمات والمهمات مباشرة |
| التواريخ | قارن تاريخ الاستحقاق بالرئيسية وحساب الوحدة | نفس الصيغة يوم/شهر/سنة؛ وقت العمليات بتوقيت القاهرة |
| الخصوصية | افتح حساب عضو حُجبت عنه مستحقات الوحدة | المستحقات محجوبة والصندوق العام والمشاوير متاحان |
| تبديل الوحدة | بدّل الوحدة أو الصفحة أثناء التحميل | لا تظهر بيانات الوحدة أو الصفحة السابقة فوق الحالية |
| إجراءات الحارس | من الرئيسية افتح إجراءات | التسوية والمسافات متاحتان حسب الصلاحية، والمشوار والحساب كما هما |

تجارب الشاشة والأونلاين على المستخدم، ولم تُنفّذ تلقائيًا.
