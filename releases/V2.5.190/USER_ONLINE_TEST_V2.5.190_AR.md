# تجارب الإصدار V2.5.190

شغّل SQL242 المرفق ثم ارفع ZIP التشغيل V2.5.190. التجارب التالية من حساب ساكن في الوحدة المقصودة، على الكمبيوتر والموبايل عند مراجعة الشكل.

| التجربة | تعمل إيه؟ | النتيجة المطلوبة |
|---|---|---|
| آخر تسوية | اضغط رقم آخر تسوية في كارت الحارس | تفاصيل نفس التسوية؛ لو ملغاة تظهر «ملغاة» ولا ينتقل للرابط لتسوية أقدم |
| الأزرار | راجع الكارت | «+ مشوار» و«الحساب» و«تسوية» مباشرة، وأيقونة إعدادات، بدون قائمة «إجراءات» |
| الإعدادات الموحدة | افتح الأيقونة | المسافات والأتعاب والمسافة الافتراضية وحد المبلغ وعدد الأيام، مع زر «حفظ» واحد |
| حفظ ومزامنة | حدد مبلغًا وأيامًا واحفظ ثم افتح نفس الوحدة من جهاز آخر | القيم محفوظة مع نفس صلاحيات تعديل المسافات الحالية |
| حد المبلغ | ضع حدًا أقل من أو مساويًا للمطلوب المعروض واحفظ | المطلوب وعدد المشاوير المفتوحة بالأحمر مع توضيح السبب، والأرصدة لم تتغير |
| حد المدة | امسح حد المبلغ وحدد أيامًا أقل من أو مساوية لعمر أقدم مشوار مفتوح | الأحمر عند مرور أيام كاملة؛ لو لم تمر يظل أصفر |
| إيقاف التنبيه | امسح الحدين واحفظ | مديونية موجودة ومشاوير مفتوحة بالأصفر؛ بدون حد أحمر افتراضي |
| الرصيد الدائن | راجع كارتًا به رصيد دائن وكارتًا بدونه | الموجود أخضر، وغير الموجود «لا يوجد» أصفر؛ المطلوب صفر «لا يوجد» أخضر |
| تبديل الوحدة | افتح الإعدادات ثم بدّل الوحدة أو الصفحة أثناء التحميل | لا تظهر نافذة أو بيانات الوحدة السابقة في الجديدة |
| حفظ غير صالح | أدخل صفرًا أو قيمة سالبة أو أيامًا فوق 3650 | لا يُحفظ إعداد غير صالح؛ الإدخال الصحيح يُحفظ مرة واحدة |

لا يلزم إنشاء أو إلغاء تسويات فعلية لمراجعة الروابط والألوان والإعدادات. تجارب التسويات المالية السابقة لم تُعتبر مقبولة بمجرد اختبارات هذا الإصدار.
