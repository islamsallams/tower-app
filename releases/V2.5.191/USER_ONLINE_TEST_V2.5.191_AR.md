# تجارب الإصدار V2.5.191

شغّل SQL243 الجديد ثم ارفع ZIP التشغيل V2.5.191. راجع حساب الساكن على الكمبيوتر والموبايل.

| التجربة | تعمل إيه؟ | النتيجة المطلوبة |
|---|---|---|
| الخط | افتح إعدادات المشاوير | شرح أصغر وخفيف، وعناوين وإدخالات بحجم متناسق مع التطبيق |
| ملخص الرئيسية | راجع كارت الحارس | ثلاثة كروت منظمة للرصيد الدائن والمشاوير المفتوحة وآخر تسوية، بنفس ألوان وحدود التنبيه المحفوظة |
| الروابط | اضغط كل كارت صغير | الدائن يصل للدفعات، والمفتوحة لقائمتها، وآخر تسوية لتفاصيل نفس الرقم |
| ملخص صفحة المشاوير | افتح الصفحة وراجع كارت الملخص | نفس توزيع الأرقام والألوان والروابط، وأزرار «دفعة / تسوية / الإعدادات» بأيقونات |
| الأزرار | راجع الرئيسية | «مشوار» بأيقونة إضافة، و«الحساب / تسوية / إعدادات» بأيقونات ونص، مع نفس الصلاحيات |
| مستحقات الوحدة | راجع الإجمالي وتقسيم الاتحاد والخدمات والمهمات | المتبقي المسجل لكل قسم، والإجمالي يجمعه دون المشاوير أو تكرار تحصيل الخدمة |
| وجهات الأقسام | اضغط الاتحاد والخدمات والمهمات من الكارت ومن ملخصه | حساب العمارة أو تبويب الخدمات أو المهمات المطلوب، والنافذة تغلق دون إعادة الصفحة السابقة |
| حماية القراءة | بدّل الوحدة أثناء تحميل ملخص المستحقات | لا تظهر بيانات الوحدة القديمة في الجديدة |
| الخصوصية | من عضو عادي في وحدة حجبت حسابها | حساب الوحدة محجوب، والمشاوير والصندوق العام يظلان وفق صلاحياتهما الحالية |

لا يلزم تسجيل مشاوير أو سداد أو تسويات حقيقية لمراجعة التنسيق والتنقل. قارن الإجمالي بالمستحقات المسجلة، لا بأسعار الاشتراكات أو نصيب مهمة لم يعتمد بعد.
