# إصدار V2.5.195 — تنظيم ملخص صفحة المشاوير وإجمالي الدفعات

- تطبيق التوزيع المعدل المعتمد: صافي الحساب أول صف بعرض كامل، وتحته أربعة كروت في صفين وعمودين على الكمبيوتر والموبايل، دون كارت أقدم مشوار.
- الحفاظ على المسميات القائمة بدل نقل أسماء الصورة: الكارت الأول «المطلوب للحارس» أو «رصيد دائن» حسب الحالة، ثم «إجمالي الحساب» و«الدفعات تحت الحساب» و«مشاوير مفتوحة» و«آخر تسوية». لا تغيير للمسميات أو نصوص البنود والدفعات القائمة بسبب الصورة التخيلية.
- تاريخ ووقت آخر تسوية بخط صغير من منسق النظام الحالي. التسوية الملغية تظل هي الأخيرة ولا تُستبدل بأقدم فعالة، مع حالتها ورقمها بالأحمر ورابط تفاصيلها الأصلي.
- إجمالي الدفعات وعددها داخل عنوان «الدفعات تحت الحساب»، بنفس بيانات الحساب الحالي. الإجمالي من paymentsTotal الأصلي ويقرب للعرض مرة واحدة، دون جمع المبالغ المقربة من الكروت، ولا استبداله بعدد أو مبالغ اللقطة التخيلية.
- الكروت أزرار حقيقية قابلة للوصول بلوحة المفاتيح: الصافي يفتح الحساب، إجمالي الحساب وعدد المشاوير يفتحان المفتوحة، الدفعات تفتح قسمها، وآخر تسوية تفتح تفاصيلها أو السجل عند عدم وجود تسوية.
- الألوان تراعي حدود التنبيه الحالية، والرصيد الدائن أخضر، والمبلغ المطلوب أصفر/أحمر حسب الحالة، والبيانات غير المتاحة لا تتحول إلى صفر. العملة تحت مبلغ الكروت، مع عزل الأرقام واتجاه التواريخ.
- الحفاظ على نموذج إدخال المشوار ومكانه وأزرار الصفحة الحالية ومسمياتها وصلاحياتها. لم تُنقل إجراءات أو تُجمع في قائمة. لا تعديل لرئيسية الساكن أو حساب الحارس أو إنشاء/تعديل/إلغاء المشاوير أو المدفوعات أو اعتماد التسوية ومعاينتها أو التراجع أو SQL246.
- الشبكة تستعمل أعمدة مرنة وتمرير الصفحة الطبيعي وروابط الأقسام الحالية بمسافة الوقوف المعتمدة أسفل الهيدر، دون ارتفاع ثابت أو محتوى مقصوص أو شريط عائم جديد.
