# إصدار V2.5.197 — أزرار الحارس وترتيب الاختصارات وألوان المشتريات

- زر «إضافة» مع أيقونة+حقيقية بعرض كارت تسجيل الحارس، وزر «إرسال» بعرض الكارت بنفس معرف ومعالج التسجيل القائم. بقية نماذج البنود تحتفظ بزر «+ إضافة بند» كما كان.
- البحث يحمل النص الإرشادي داخل الحقل؛ يختفي عند التركيز ويرجع عند الخروج إذا كان الحقل فارغًا. اسم البحث الميسر aria-label دائم، ونفس معالجات البحث واختيار الوحدة والمسح دون تغيير. حذفت الجملة المشطوبة من رأس التسجيل.
- حذف كلمة «المفضلة» من العرض مع بقاء أزرار الوحدات والأخيرة. أيقونة ترتيب صغيرة تظهر تقديم/تأخير لكل وحدة؛ انتهاء الترتيب بعلامة التأكيد. اختيار الوحدة نفسه ما زال بنفس الزر والمعالج.
- الترتيب يُحفظ لنفس الحارس في نفس المتصفح، باستخدام قائمة المفضلة الحالية وحد8، دون API أو قاعدة بيانات أو مزامنة أجهزة. تبديل المستخدم أو الجلسة يمنع استعمال حالة ترتيب قديمة. الوحدات غير المتاحة المحفوظة وقائمة الأخيرة وبنود المشوار غير المحفوظة ومرجع التسجيل محفوظة؛ تعذر التخزين يظهر رسالة عربية.
- مشتريات اليوم بالأزرق، وتسويات اليوم بالأخضر، والمفتوحة بالأصفر مع تظليل وحدود خفيفة وأيقونات وأعداد من نفس اللون. المبلغ الصفري والبيانات غير المتاحة محايدان. نفس المجاميع الخام وSQL247 دون تغيير.
- توحيد صفوف كروت الملخص: الأيقونة ثم مساحة العنوان ثم المبلغ ثم العدد، مع مساحة فارغة محجوزة لسطر العدد في مشتريات اليوم ومخفية عن قارئ الشاشة، دون اختلاق عدد. العناوين تلتف دون قص، والأرقام تتقابل على نفس المستوى في العرض المعتاد.
- شريط «إجمالي المشتريات» داخل المشوار بخلفية زرقاء خفيفة وحد رفيع، والمبلغ أكبر بدرجة واحدة والعملة أصغر تحته، عبر نفس amountText وتقريب العرض الحالي دون تعديل أي مبلغ محفوظ.
- التسجيل أول الصفحة، والقوائم قابلة للطي، والبنود المتتابعة ونقطة السعر غير المحدد والتسوية وPDF والساكن والأتعاب والمسافات وكتابات الحساب والتراجع والإلغاء كما هي. الـWorker رقم الإصدار فقط؛ لا SQL جديد.

## التثبيت والتحقق

ارفع ZIP التشغيل V2.5.197 فقط، واحتفظ بـSOURCE. لا SQL جديد لهذه الدفعة ولا تشغيل تلقائي لأي SQL من الحزمة.

نجحت اختبارات الكود والنماذج والقراءات والتخزين المصطنع وتحضير الحزمة. لم يتم اختبار واجهة أو متصفح أو PDFأو قاعدة حية أو نشرCloudflare؛ المراجعة البصرية والأونلاين للمستخدم دائمًا.
