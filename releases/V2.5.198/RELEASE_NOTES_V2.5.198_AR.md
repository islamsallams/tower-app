# إصدار V2.5.198 — نافذة لإدارة مفضلة الحارس

- استبدال أزرار تقديم/تأخير المتزاحمة تحت الاختصارات بزر «ترتيب» يفتح نافذة صغيرة. كل صف يعرض الوحدة ومديرها ودورها، مع سهمين لأعلى ولأسفل وإزالة من المفضلة.
- إضافة ساكن من بحث داخل النافذة بنفس وحدات سياق الحارس وبيانات البحث القائمة، بما فيها اسم أي عضو عند توفره في سياق البحث. لا طلبAPIجديد أو دليل مستخدمين مستقل.
- النافذة تعمل بمسودة؛ الترتيب والإضافة والإزالة لا تحفظ قبل «حفظ». «إلغاء» أو×أوالرجوع يغلق دون تعديل القائمة. الحفظ يكتب القائمة النهائية مرة واحدة بنفس مفتاح المتصفح وحد8الموجود، ولا يسجل حركة مالية أو يختار وحدة بدل الحالية.
- طريقة النجمة في قائمة اختيار السكان من حقل البحث بقيت بدوالها وسلوكها الأصليين تمامًا؛ الإضافة والحذف منها فوريان كما كانا. قائمة الأخيرة ومدخلات المشوار ومرجع إرساله لا تتغير.
- زر الإدارة موجود حتى لو المفضلة فارغة، لإتاحة أول إضافة. قائمة الإضافة قابلة للفرد والطي، والنتائج والقائمة الطويلة قابلة للتمرير. حدود الأسهم تعطل عند أول وآخر صف، ويُحافظ على تركيز لوحة المفاتيح دون انقلاب اتجاه الحركة عند الحدود.
- الاختصارات التي لم تعد بياناتها متاحة لا تحذف تلقائيًا؛ تظهر كاختصار غير متاح وتظل قابلة للترتيب أو الإزالة الصريحة دون عرض معرفات تقنية.
- مسودة مستخدم أو جلسة أو صفحة أو نافذة سابقة لا تحفظ، والتغيير الأحدث للمفضلة لا يكتب فوقه تلقائيًا. فشل التخزين يترك النافذة والمدخلات للمحاولة ولا يعرض نجاحًا كاذبًا.
- الحفظ محلي لنفس المتصفح والحارس، ولا يزامن بين الأجهزة. لاSQLجديد، ولا تغيير للحسابات والتسجيل والإلغاء والتسوية والتراجع أو البنود المتتابعة ونقطة السعر وPDFأوألوان ومحاذاة الملخص197. الـWorker إصدار فقط.

## التثبيت والتحقق

ارفع ZIP التشغيل V2.5.198 فقط، واحتفظ بـSOURCE. لا SQL جديد لهذه الدفعة ولا تشغيل تلقائي لSQLمن الحزمة.

نجحت اختبارات الكود والنماذج المصطنعة والتخزين والتحضير. لم ينفذ اختبار واجهة أو متصفح أوPDFأواتصال قاعدة حية أو نشرCloudflare. تجربة الشاشة والموبايل والأونلاين على المستخدم دائمًا.
