# إصدار V3.0.0 — تجميعة الهوية والطلبات والمشاركة

## التغييرات

- بداية تسلسل SemVer من V3.0.0 حسب اتفاق المستخدم؛ الإصدارات السابقة وترقيم SQL محفوظان دون إعادة ترقيم. الإضافات اللاحقة المتوافقة MINOR والإصلاحات PATCH والتغييرات الكاسرة MAJOR.
- نافذة مستحقات الوحدة: أيقونتا نسخ ومشاركة لنص منظم من نفس لقطة الأرقام المعروضة، مع اسم النظام ورقم الوحدة والدور ونوع الوحدة ومديرها بلقبه عند توافرها، والإجمالي وتقسيم الاتحاد والخدمات والمهمات واستثناء المشاوير وتاريخ البيانات عند وروده. لا إضافة لهاتف أو معرفات تقنية. المشاركة تستخدم واجهة الجهاز وتعود للنسخ عند عدم توفرها؛ الإلغاء يتبع السلوك القائم. لا استعلام إضافي عند الضغط ولا مشاركة تلقائية. تبديل الحساب أو الجلسة أو الوحدة أو إغلاق/استبدال النافذة يمنع تصدير اللقطة القديمة.
- الصورة الرئيسية تُستخدم خلفية للدخول: نصف الشاشة الأيسر على الكمبيوتر والعلوي على الموبايل، والكارت يظل في منتصف الشاشة بالكامل. النصف الآخر بلون الثيم وتدرج خفيف عند الحد. لا فيديو أو GIF أو تحميل متحرك.
- هوية النظام: أربعة أقسام للاسم والشعار النصي والألوان واللوجو وخلفية الدخول (الاسم والشعار قسم واحد)، مع معاينة للألوان وموضع الصورة لكل جهاز بصورة مستقلة. حفظ واحد للحقول والصور بالطريقة القائمة؛ الصور لا تُرفع بمجرد اختيارها أو حذفها من المعاينة. فشل جزء من الحفظ يظل موضحًا ولا يدّعي نجاح العملية كلها. لم يُحوّل حفظ ملفات الصور إلى معاملة قاعدة بيانات واحدة.
- خطوط النظام في قسم مستقل، وحجم الخط الشخصي في الحساب والمظهر. تنبيه عند مغادرة مسودة الهوية غير المحفوظة، ومعاينة الصورة والقص والألوان محلية حتى الحفظ. فحص المقاسات والصيغ وضغط الصور قائم كما كان.
- الحساب غير النشط: رسالة عربية واضحة بدل الخطأ العام، مع المرجع ونسخ التفاصيل. يُستدعى فحص الدخول الأصلي أولًا، ولا تُقرأ كلمات السر ولا يُنشأ رمز جلسة جديد خارج محرك المصادقة؛ عند الفشل أو عدم إرجاع جلسة يُتحقق من الحالة فقط. لا تجاوز لرفض الدخول أو لتحديد المحاولات.
- توحيد التوجيه بالنقطة الحمراء للطلبات التي تحتاج إجراء من المستخدم الحالي: التسجيل والعضوية واشتراك الخدمات والمهمات وتعديل الاشتراك وطلبات إدارة المهمة واسترجاع PIN واعتماد تقارير التحصيل حسب صلاحيات المصادر القائمة. مدير الوحدة يرى طلبات وحداته التي لم يُبدِ رأيه فيها، ومسؤول المهمة يرى الاشتراكات التي يحق له مراجعتها؛ مقدم الطلب المنتظر قرار شخص آخر لا يحصل على نقطة تطلب منه إجراء غير متاح.
- النقطة في اسم الصفحة والمزيد والهامبرجر عند الحاجة، ثم قسم الإعدادات والكارت أو التبويب والسجل المرتبط. قسم بالاعدادات يعرض الطلبات التي تحتاج إجراء مع روابط وجهاتها. فتح الصفحة لا يعالج الطلب ولا يطفئ النقطة؛ الحالة تتحدث بعد الإجراء والتنقل والعودة للنافذة، دون مؤقت استطلاع بالخلفية أو إشعارات خارجية.
- طلب PIN بحالة PENDING يحتاج إصدار كود، أما ISSUED فيظل في شاشة الطلبات دون نقطة إجراء جديد. طلبات المدير الاستشارية تظل للإدارة حتى القرار النهائي، وتنتهي إشارة المدير بعد إبداء رأيه. فشل مصدر إضافي يظهر تعذر تحديثه ولا يعامل كصفر؛ تُحفظ آخر علامات صحيحة عند فشل القراءة.

## التثبيت

شغّل SQL251_BRANDING_AND_PENDING_ACTIONS_V3.0.0.sql ثم ارفع Tower_App_V3.0.0.zip. الملف مستقل ولا ينفذ برفع ZIP، ولا تعِد تشغيل ملفات SQL القديمة.

SQL251 يضيف إعداد موضع خلفية الدخول ودالة حفظ تستدعي إعدادات النظام القائمة، ودالة قراءة مجمعة للطلبات بصلاحيات المستخدم الحالي. لا تعديل لمحرك المشاوير أو التسويات أو المبالغ أو بيانات الطلبات بمجرد قراءتها. المصدر يحتفظ بجميع المسارات السابقة والأرشيف التاريخي.

هذه التجميعة فقط؛ النسخ الاحتياطي والاستعادة وتنزيل نسخة التشغيل ومراجعة التصفير وفصل أرشيف SOURCE ما زالت مؤجلة. اختبار الواجهة والأونلاين للمستخدم، ولم ينفذ المساعد SQL أو نشرًا على النظام الحي.

تم الحفاظ على ضبط موضع صورة شاشة الترحيب القديمة في جزء قابل للفرد والطي داخل قسم الصورة، مستقلًا عن مواضع خلفية الدخول الجديدة.
