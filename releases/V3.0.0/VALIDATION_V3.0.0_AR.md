# فحوص الإصدار V3.0.0

- فحوص جديدة:6نماذج نسخ/مشاركة،4تنظيم الهوية والمسودة وCSS،7حالة الطلبات والتوجيه والتزامن،8SQL251بقاعدة PGlite مصطنعة،6WorkerHTTP ببديل fetch.
- SQL يشمل عزل المدير والعضو والمسؤول وإعادة الإسناد والمهمة المغلقة، أكثر من1100طلب، القراءة دون تغيير حالات، إعدادات كل جهاز والحفظ المتكرر والرفض والرجوع عند فشل الحفظ وصلاحيات الدوال والجدول.
- HTTP يشمل رسالة الحساب غير النشط عند فشل/فراغ الدخول، ونجاح الدخول الأصلي، وعدم تجاوز تحديد المحاولات، وعدم قراءة رمز PIN أو إرجاع بيانات الطلبات الإدارية لمستخدم عادي، وعدم تحويل فشل مصدر إلى صفر، وحماية الهوية للأدمن فقط.
- الانحدار:9صفحة الأمين،12المفضلة،8معاينة التسوية،5مساراتها Worker،4ملخص الأمين،4تفضيلات الخط Worker،6الكروت،5حركة الهيدر،11قراءة المستحقات وإصلاحSQL250.
- ذيل التسويات والأمين والمفضلة مطابق للإصدار200 بعد استثناء رقم الإصدار والعنوان. لا إعادة تعريف لمحرك مالي أو كتابة مالية في251. الاختبار القديم لتوقع جملة محذوفة من نموذج التسوية لا يُحسب نجاحًا ولا يعاد تغيير أدلته، وتوقعات تخطيط199التاريخية محفوظة لإصدارها.
- فحوص تجهيز Updaterبعد بناء الحزمة:7ناجحة، دون تشغيل الواجهة أو النشر. الترقيم3.0.0يُكتشف من الحزمة، ومسار التشغيل خمسة ملفات جذرية، مع تطابقpublicومصدرها وCRCوحفظ كل تاريخ المصدر.
- لا اختبار متصفح أو شاشة أو توليد PDF أو حسابات حقيقية أو SQL أونلاين أو نشر على Cloudflare. فحص الواجهة والأونلاين للمستخدم دائمًا.
