- خمسة فحوص انحدار للرسام مع دالة تركيب المراقب الفعلية وبدائل DOM/Microtask: V3.0.0يعيد توليد نفسه بعد20دورة، والمصحح يستقر؛ لا كتابة للنص نفسه، ولا كتابة للخصائص نفسها، وتحديث العدد والإزالة والخطأ مستمر. لا متصفح أو اختبار شاشة.

- لا SQL أو نشر أو إشعارات أو كتابة مالية أو توليد PDF أو متصفح أونلاين. تجربة الشاشة والأجهزة على المستخدم دائمًا.
