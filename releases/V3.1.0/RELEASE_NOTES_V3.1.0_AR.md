# إصدار V3.1.0 — إعادة تصميم هوية النظام

تحويل قسم الهوية من نموذج طويل ومتداخل إلى مساحة تعديل بأربعة تبويبات: الاسم، الألوان، اللوجو، الصورة.

- الكمبيوتر: أدوات التعديل يمين، ومعاينة حية واحدة أكبر يسار. الموبايل: تبويبات ثم معاينة واحدة ثم أدوات التبويب المختار.
- الاسم واللوجو والشعار النصي يظهرون معًا؛ الألوان تتعاين على زر وحالة عرض مع اختيار لون نص مقروء داخل المعاينة فقط.
- صورة الدخول لها اختيار الكمبيوتر أو الموبايل أو الترحيب، مع إظهار منزلقَي الموضع المناسبين فقط. تظل المواضع الستة مستقلة ومحفوظة بنفس الطريقة السابقة.
- صور مصغرة واختيار ملف واضح، وإظهار اللوجو الافتراضي عند الاستعادة، وحالة تغييرات غير محفوظة وزر حفظ واحد. تبديل التبويبات والمعاينة لا يمسح المسودة ولا يحفظ تلقائيًا.
- إزالة عنوان الهوية الداخلي المكرر والإطارات المتداخلة. استخدام لوحة المفاتيح للتبويبات ودعم الثيم الحالي.

## التثبيت

ارفع Tower_App_V3.1.0.zip فقط. لا SQL جديد. احتفظ بملف SOURCE للتطوير والأرشيف.

حفظ الإعدادات ورفع الصور وصلاحياتها كما هي؛ لا تعديل للحسابات أو المشاوير أو التسويات. فحوص الكود محلية، وتجربة الشكل والموبايل والحفظ أونلاين على المستخدم.
