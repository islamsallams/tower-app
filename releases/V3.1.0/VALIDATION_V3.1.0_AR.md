# فحوص الإصدار V3.1.0

- ثمانية فحوص نموذج هوية جديد: تبويبات ومعاينة وحفظ وحيد، مسودة مستقلة، ألوان ولوجو ونص محلي، مواضع الأجهزة، ثبات التحديث، أسهم RTL، وصحة الحقول المخفية وتفويض الحفظ الأصلي.
- خمسة فحوص انحدار تجمد مراقب الإعدادات، وسبعة للطلبات، وستة لنسخ ومشاركة المستحقات، وستة Worker، وستة للكروت، وخمسة لحركة الهيدر.
- أربعة فحوص حفظ النطاق: محرك المشاوير والتسويات مطابق، Worker إصدار فقط، CSS القديم محفوظ، وQA التاريخي مستعاد من المصدر السابق. فحص صياغة app.js وworker.js ناجح.
- سبعة فحوص تجهيز حزمة Updater محليًا، دون واجهة أو رفع. CRC ومطابقة public والجذر، وحفظ جميع مسارات المصدر السابق والاختبارات وSQL التاريخية دون تغيير.
- لا SQL جديد أو تشغيل SQL أو نشر حي أو اختبار متصفح/واجهة أو صور تلقائية أو PDF أو كتابة مالية. القبول البصري وتجربة الأجهزة والحفظ أونلاين للمستخدم.
