# Tower App V3.16.0

دمج «طلبات جديدة» و«قيد التنفيذ» عند الأمين في «جاري التنفيذ»، مع «بانتظار التسوية» و«السجل». عند الساكن تبويبان للمشاوير المفتوحة والسجل.

فلاتر الحالات أزرار ملونة قابلة للتبديل، تتقاطع مع الوحدة وأسعار البنود. الأعداد على التبويبات للإجمالي، وعلى فلاتر الحالة للنتائج ضمن الوحدة والأسعار المختارة. لكل تبويب اختياراته وصفحته المستقلة، والعرض ستة مشاوير في الصفحة. مسح الفلاتر يرجع الكل.

الكروت بحد ملون وشارة بنفس لون فلتر الحالة، بألوان مستقلة للفاتح والداكن. ترتيب كارت الأمين الهوية والحالة والتاريخ ثم البنود والملاحظات والمشتريات والإجراءات. أزرار التنفيذ أوضح، والأسماء الطويلة تلتف، والإجراءات متناسبة مع الحالة. لا تغيير لقيم المبالغ أو عناوينها؛ النقط الحمراء تظل العلامة على السعر الناقص.

تعديل مهلة الساكن من الكارت قبل المشاهدة فقط، عبر الدالة القائمة في SQL289. الحساب من وقت إنشاء الطلب كما هو؛ المهلة لا تتجدد من وقت التعديل. عند فشل الحفظ يعود الاختيار لقيمته المحفوظة. لا تعديلات على SQL.

إصلاحان مرتبطان بالعرض: منع فتح محرر مشتريات لمشوار معتذر عنه أو ملغى أو منتهي عند الأمين؛ واحترام قائمة الحالات التي ترجعها SQL289 حتى لا يعود المشوار المخفي كحالة نشطة افتراضية.

## التثبيت

ارفع حزمة تشغيل V3.16.0 بالـUpdater المعتاد ثم حدّث الصفحة. لا SQL جديد مطلوب لهذه الدفعة. SQL289 الذي أكد المستخدم نجاحه محفوظ دون تعديل في المصدر للاحتفاظ بالتاريخ، وليس طلبًا لإعادة تشغيله. هذه حزمة ويب ولا تتضمن إصدار APK جديدًا.

## التحقق

نجحت 13 مجموعة اختبار DOM وحالات وفلاتر وحفظ المهلة، و8 اختبارات بدء ودخول مع مقدمة const KEY/URL المصطنعة. نجحت 5 مجموعات توافق لدالة SQL289 الفعلية على PGlite بصفوف مصطنعة؛ خدمات الانتهاء والإشعارات بدائل محلية ولا تمثل اختبار دورة مالية أو إرسال حقيقي.

نجح تحليل JavaScript وCSS وبناء Worker التجريبي دون نشر. تحقق حسابي من تباين ألوان الحالات السبعة في الفاتح والداكن مع خلفيات الشارات بنسبة لا تقل عن 4.5:1. المقارنة البنيوية تؤكد بقاء كل دوال التطبيق الأصلية دون تغيير خارج 11 دالة لواجهة المشاوير؛ Worker تغير رقم إصداره فقط. ملفات SQL والتقارير وحسابات التسوية لم تتغير.

تحذير البناء القائم عن مفتاح REQUEST_ALREADY_REVIEWED مكرر في Worker محفوظ من المصدر السابق؛ لا يمنع البناء. الاختبارات التاريخية المثبتة على أرقام إصدارات قديمة ليست قبولًا لهذا الإصدار ولم يتم إعلان نجاحها الشامل.

لم يُشغّل متصفح أو هاتف أو محاكي، ولم يُجر قبول بصري أو تشغيل SQL حي أو نشر أو إرسال إشعارات. ملاءمة الشكل الفعلية للموبايل والكمبيوتر في الوضعين تحتاج تجربة المستخدم.
