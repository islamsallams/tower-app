# فحوص الإصدار V3.4.0

الفحوص محلية للكود فقط، وليست قبولًا للواجهات أو اختبارًا على قاعدة المستخدم الحية.

- نماذجNodeللثيم بمخزن مشترك بين تبويبات افتراضية: فصل الحسابات، تزامن نفس الحساب، فصل صفحة الدخول، وحفظ الاختيارات محليًا دون خادم.
- نموذجDOMعبرlinkedomللمركز: جرد المداخل والفلاتر والصفحات والعدّاد والنقطة، منع تكرار تنبيه المشوار، الروابط، إقرار القراءة بالمراجعة المحددة، ومنع الرد المتأخر بعد تبديل الحساب. لا متصفح أو رسمCSS.
- نموذج الدخول العام يختبرbootAppوshowLoginوapplyBrandingوapplyUiPreferencesالفعلية ببدائل نقل/صور محلية؛ الاسم والشعار والمواضع وFadeوالمقاس والمسافة والخطوط قبل المصادقة، وحماية الصور القديمة بعد الاستعادة. فحص ثابت لقواعدCSSالتي تغلبت على المقاس الأفقي؛ الشكل الحقيقي للمستخدم.
- WorkerببدائلHTTPمحلية: الدخول والصلاحيات والـPIN، قراءة الخطوط العامة دون تفضيلات حساب، تجميع الإشعارات وإظهار المصدر غير المتاح، وإقرار المشوار للأمين فقط. انحدار التصفير يثبت بقاء الحذف متوقفًا والمعاينة للقراءة فقط.
- SQL256فيPGliteعلى مخطط مصطنع مبني على المهاجرات المتاحة: الحفظ الذري مع252و251والخطوط، المسافة السالبة، عدم فقد المقاس في حفظ الأمان، rollbackللخطأ، الأنواع والحدود والأذونات وإعادة التثبيت. قراءة الخطوط العامة تختبر قائمة حقول العرض فقط. وظائف الحفظ القديمة بدائل محلية؛ ليست نسخة من كل قيود قاعدة المستخدم.
- SQL257فيPGlite: اشتقاق مشاوير الساكن المفتوحة فقط، القراءة المستقلة لكل أمين، تغير المراجعة يعيد غير المقروء، رفض المعرفات والحالات والأدوار غير المسموحة، واختفاء المسوّى، مع بقاء قيم وحالة المشوار دون تغيير بسبب القراءة.
- انحدارات الهوية والمسودة والافتراضي وحفظ التبويب، قوائم الإدارة والعضوية وأنواع الوحدات، الإشعارات الشخصية والمراقبة ومعاينة التصفير، مراقبDOMوالكروت والطيف. اختبارات محفوظة بلا تعديل لعقود الإصدارات القديمة، ونُسخت أدلة التشغيل الجديدة فقط إلىqa/v3.4.0ثم استعيدتQAالتاريخية.
- حماية نطاق: ذيل المشاوير/التسويات المالي فيapp.jsومسارات المحرك القائمة فيWorkerمطابقة للنسخة السابقة، وكلSQLوالاختبارات السابقة محفوظة، وCSSالأصلي باقٍ كبداية ملف قبل الإضافات.
- تجهيزUpdaterمحليًا عبر استخراج وظائف فحصZIPوتحضير أصولCloudflareمنUpdater2.1.11دون تشغيل الواجهة أو النشر. ZIPالتشغيل5ملفات جذر فقط، وتطابقpublicوالجذر، وفحصCRCوتاريخSOURCEوالملفات الجديدة.

التعداد النهائي لكل مجموعة وSHA256لملفات التسليم فيdelivery-checks.json. لم يُشغّل متصفح أوPlaywrightأوPDFأوSQLحي أو نشر أو رسالةTelegramأو كتابة مالية.
