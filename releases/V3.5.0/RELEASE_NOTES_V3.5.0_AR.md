# إصدار Tower App V3.5.0

تجميعة الإشعارات وحالات الوحدات والأسماء وأدوات مراجعة البيانات. هذه نسخة تنفيذ محلي؛ الشاشات والأونلاين لم تُختبر بواسطة المساعد.

## التثبيت

شغّل الملفات الجديدة فقط بهذا الترتيب: SQL259_NOTIFICATION_HISTORY_V3.5.0.sql، ثم SQL261_SPLIT_PERSON_NAMES_V3.5.0.sql، ثم SQL262_UNIT_STATES_V3.5.0.sql، ثم SQL263_ADMIN_DATA_REVIEW_V3.5.0.sql. بعد نجاحها ارفع Tower_App_V3.5.0.zip. ملفات SQL مستقلة ولا تعمل برفع ZIP. لا تعِد SQL258 أو SQL260 أو ملفات الإصدارات السابقة.

## الوحدات ودليل الألوان

- تحت الفلاتر يظهر دليل الألوان: نقطة بلون كل حالة وبجانبها اسمها، ويلتف على الموبايل. يتغير مع تعديل الحالة أو اللون.
- البادج يعرض نوع الوحدة، والسطر الصغير يعرض الدور، والحافة الملونة تمثل الحالة. التصفية بالحالة تستخدم هويتها المستقلة.
- تبويب حالات الوحدات لإضافة الاسم واللون والإعفاء من العمارة والخدمات والمهمات بشكل مستقل. الحالة المستخدمة لا تُحذف، والحالتان الأساسيتان محفوظتان. الإتاحة للسكان منفصلة عن الإعفاء المالي.
- التغيير يخص الاستحقاقات الجديدة فقط، ولا يمس سدادًا أو دينًا سابقًا. التوزيع المتساوي يحسب المشاركين المؤهلين قبل الأنصبة؛ الإعفاء لا يُنفّذ بإسقاط صف بعد حساب نصيبه.
- أي مسار بديل يحاول إنشاء دين جديد للوحدة المعفاة يُرفض بالكامل؛ لا يُحفظ جزء من العملية. راجع المشاركين والتوزيع المخصص أو التسوية الجديدة عند ظهور هذا السبب.
- تجديد الخدمة المعفاة يتخطى الفترة ويقدم موعد التجديد؛ لا ينشئ دين الفترة عند إزالة الإعفاء لاحقًا. الإعفاء لا يلغي اشتراكًا تاريخيًا أو مستحقاته السابقة.

## الإشعارات والأسماء

قراءة الإشعار فورية ومستقلة عن فتح المصدر والقرار المطلوب. يظل المقروء في الكل، بما في ذلك سجل تنبيه المشوار بعد الإلغاء أو التسوية. فشل حفظ القراءة يعيد الحالة السابقة ويعرض إعادة المحاولة؛ فشل المصدر لا يلغي القراءة الناجحة. فتح التفاصيل الأصلية المدعومة يقر بقراءة إشعاراتها أيضًا. بيانات الحساب الآخر والردود المتأخرة لا تُطبّق على الجلسة الحالية.

تحديث تلقائي كل8ثوانٍ عند ظهور الصفحة، وعند الرجوع أو التنقل؛ ليس اشتراك Push عند إغلاق التطبيق. الصوت متوقف ابتداءً ولكل حساب ومتصفح/جهاز اختيار مستقل. يحتاج تفعيلًا أو تجربة بإيماءة من المستخدم؛ Web Locks تمنع تكراره في تبويبات نفس الحساب. إعادة فتح القائمة أو إعادة جلب نفس الإشعار لا تعيد الصوت.

الاسم الأول وباقي الاسم حقول مستقلة في النماذج الفردية، واللقب مستقل عنهما. الاسم الكامل محفوظ للتفاصيل والتقارير. الأسماء القديمة تُقسم أول كلمة والباقي حسب موافقة المستخدم. الاسم الأول الجديد يدعم مثل «عبد الرحمن» كاملًا في الحقل الأول. الهيدر يعرض اللقب والاسم الأول.

## النسخة المشفّرة وأدوات البيانات

تنزيل نسخة بيانات من شاشة الإدارة يجمع كل جداول التطبيق في public تحت قفل قراءة متسق، ثم يشفرها المتصفح AES-256-GCM بمفتاح مشتق من كلمة مرور عبر PBKDF2-SHA256 و310000دورة. كلمة المرور لا تُحفظ أو تُرسل للخادم. تشمل النسخة الحسابات وبيانات التحقق والمرفقات؛ احفظ الملف وكلمة مروره بأمان. الحد المدعوم للبيانات نحو30MiB؛ تجاوز الحد يرفض العملية دون ملف جزئي.

النسخة تخص قاعدة البيانات، ولا تشمل أسرار Cloudflare أو KV أو إعدادات المزود الخارجي. تنزيل تشغيل الإصدار الحالي ينزل أرشيف ZIP المنشور المطابق لرقم الإصدار فقط.

**الاستعادة والتصفير لم يُتاح تنفيذهما بعد.** مراجعة ملف الاستعادة تفك التشفير محليًا وتطابق الإصدار وبصمة البنية والجداول والأعمدة وتعرض الأعداد والعلاقات، دون كتابة بيانات أو ترقية تلقائية. لا تثبت هذه المعاينة صلاحية جميع الصفوف أو نجاح استعادة فعلية. التصفير يعرض اقتراح الحذف والحفظ والجداول غير المصنفة وعلاقات المفاتيح الأجنبية. يلزم اعتماد النطاق وتجربة استعادة ورجوع على قاعدة مستقلة قبل إتاحة التنفيذ. الحظر موجود في Worker ودالة SQL وليس إخفاء زر فقط.

الأرشيف SOURCE منفصل ويحتفظ بكل المسارات السابقة والاختبارات والجرد. لاSQLحي ولا رفع Cloudflare ولا حذف أو استعادة فعلية أو إرسال Telegram بواسطة المساعد.
