# إصدار Tower App V3.7.0

فلاتر سريعة للوحدات وهيدر مضغوط على الموبايل. **لا يوجد SQL جديد؛ ارفع حزمة V3.7.0 فقط بالـUpdater.**

- العناوين أصبحت «الحالات» و«الأنواع» دون كلمة ألوان. كل عنصر زر بنقطة بلونه واسمه المسجل.
- الضغط على الحالة يختارها في قائمة الحالات، والضغط على النوع يختاره في قائمة الأنواع. الضغط على العنصر المختار مرة أخرى يلغي اختياره فقط.
- نوع واحد وحالة واحدة يمكن جمعهما مع البحث. تغيير القوائم يحدّث الأزرار أيضًا، والاختيار له إطار وخلفية خفيفة وحالة aria-pressed؛ الأزرار الأصلية تدعم Enter وSpace.
- «مسح الفلاتر» يلغي البحث والحالة والنوع معًا. تغيير الفلتر يرجع للصفحة الأولى، والتنقل بين صفحات النتائج يحتفظ بالاختيارات. العدد وعدم وجود نتائج يعكسان الفلاتر مجتمعة.
- الأنواع المعطلة تظهر بوسم معطل في الدليل وقائمة الفلترة معًا؛ لا تمنع رؤية الوحدات المرتبطة بنوع قديم. قوائم اختيار النوع عند إنشاء/تعديل الوحدة لم تتغير.
- هيدر الموبايل: +وحدة و+نوع في صف موحد، وإضافة/تعديل المجموعة في سطر صغير ظاهر، والتبويبات الثلاثة بعداداتها في صف واحد. البحث ثم قائمتا النوع والحالة، ومسح الفلاتر بجوار عدد النتائج بدل صف منفصل. دليل الفلاتر السريعة تحتهما ويلتف حسب العرض.
- على الكمبيوتر يظل العنوان والإجراءات في صف مضغوط حين تسمح المساحة. لا تُحذف أو تُدفن أدوات المجموعة أو إضافة النوع أو الوحدة أو تبويباتها.

كروت الوحدات وإجراءات التفاصيل والأعضاء كما هي. هذه فلترة عرض محلية دون API أو كتابة بيانات. محرك الحسابات وإصلاح قراءة المالية والصلاحيات في V3.6.1 كما هي؛ Worker تغير رقم الإصدار فقط. التقارير وPDF بدون تعديل، ولا تشغيل SQL حي أو نشر Cloudflare أو حذف/استعادة/إرسال بواسطة المساعد.

اختبارات الشاشات والموبايل والأونلاين للمستخدم. الفحوص المحلية لا تغلق بنود الجرد القديم أو تثبت قبول التشغيل الحقيقي.
