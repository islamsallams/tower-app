# إصدار Tower App V3.8.1

إصلاحات التنبيهات وإضافة مجموعة الوحدات ونسخ نتائج مركز الفحص وتنزيل تشغيل الإصدار الحالي. **لا SQL جديد؛ ارفع ZIP التشغيل فقط بالـUpdater.**

- صوت التنبيه أصبح نغمتين «تين تان» بطابع جرس بيانو، أعلى وأطول من السابق، بطبقات صوتية تتلاشى طبيعيًا. تشغيله الاختياري وزر التجربة وشروط فتح الصوت ومنع تكراره بين التبويبات كما هي؛ لا إرسال إشعارات تجريبية تلقائيًا.
- أصل تعطل إلغاء و× في مجموعة الوحدات كان دالة قراءة السطور معرّفة async رغم أن كل مستدعيها ينتظر مصفوفة مباشرة. صارت قراءة متزامنة؛ الإغلاق والتحقق والإنشاء يستخدمون نفس المصفوفة. عند وجود بيانات يظهر تأكيد فقدها مرة واحدة، ورفض التأكيد يحفظ السطور؛ زر الإلغاء و× ينتظران انتهاء طلب الإنشاء عند إرساله.
- كل قسم داخل ملخص نتائج مركز الفحص له أيقونة نسخ مستقلة ظاهرة وهو مغلق، تشمل عنوانه وحالته ووقت الفحص وإصداره وتفاصيله، وفحوص سلامة النظام التابعة له. الضغط لا يفتح أو يقفل التفاصيل. تنقية الروابط والرموز الحساسة محفوظة، وأيقونة النسخ ترجع بعد تأكيد النسخ.
- تنزيل التشغيل يجرب ثلاثة مسارات موثوقة من نفس مستودعGitHub:rawثمGitHubثمContentsAPI. يطلب حزمة **الإصدار الحالي المطابق** فقط، مع اسم عميل وطلب غير مخزن واستثناء الكاش القديم. الخطأ أوHTMLأوJSONبدلZIPأوتجاوز4MiBينقل للمسار التالي؛ الصلاحية للأدمن فقط ولا تعديل للاستضافة أو القاعدة. فشلها جميعًا يعطي الرسالة العربية القائمة.
- جداول تجارب الإصدار أصبحتHTMLباتجاهRTLصريح ومحاذاة يمين؛ صححنا أيضًا جدول رابط تجاربV3.8.0الذي أبلغت عنه. أرشيفاتV3.8.0نفسها محفوظة دون تعديل.

استعادةV3.8.0والتشفير وSQL265والتقارير وPDF دون تغيير وظيفي. لا تشغيلSQLأواستعادةأوحذفحيأونشرCloudflareأوإرسالخارجي. التجربة البصرية والصوتية والموبايل والأونلاين للمستخدم؛ الفحوص المحلية اختبارات كود وليست قبولًا للشاشة أو للصوت الفعلي.

نسخة التشغيل ZIP ونسخة البيانات المشفّرة ملفان مختلفان. نسخة البيانات القديمة تعمل إذا كانت بنية الجداول مطابقة؛ رقم التطبيق وحده لا يحدد التوافق. V3.8.1 لا يغير الجداول، فتظل نسخ V3.8.0 متوافقة مع نفس القاعدة. اختلاف البنية يحتاج استعادة وترقية على قاعدة منفصلة؛ الأداة الحالية لا تنفذ ترحيلًا تلقائيًا. الرجوع إلى ZIP قديم لا يرجع مخطط القاعدة بمفرده، ولا يلزم البدء من الصفر.
