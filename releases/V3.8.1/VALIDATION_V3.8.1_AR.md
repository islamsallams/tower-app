# تحقق إصدار V3.8.1

نجحت 29 مجموعة فحوص محلية: 8 نماذج كود، و7 للـWorker، و7 لحفظ الوظائف واتجاه الجداول، و7 للتغليف بكود Updater V2.3.1 الفعلي. النتائج في qa/v3.8.1 وdelivery-checks.json. لا SQL جديد.

- قراءة سطور المجموعة تعيد مصفوفة مباشرة. اختُبرت السطور الفارغة والجاهزة والمكررة، والإغلاق دون بيانات، ورفض تأكيد فقد الإدخال وقبوله مرة واحدة. زر الإلغاء ينتظر طلب الإنشاء المعلق. إنشاء مجموعة صحيحة يستدعي المسار الأصلي مرة واحدة بالوحدات الصحيحة.
- نموذج AudioContext يسجل نغمتين متتاليتين وثلاث طبقات لكل نغمة، بتلاشٍ تدريجي وسقف خلط أقل من1، ويفصل العقد بعد الانتهاء. حالة الصوت المعلّقة تمنع التشغيل. لم يُشغّل صوت فعلي أو يُقَس علوه على جهاز المستخدم؛ تفضيل التشغيل وإيماءة التفعيل وWebLocks محفوظة.
- النسخ المنفصل يشمل عنوان القسم وحالته ووقت الفحص وإصداره وتفاصيله فقط. الفحوص التابعة تضاف لقسم النظام، دون خلط قسم آخر. الروابط والرموز محجوبة بالمساعد القائم، وأيقونة SVG ترجع بعد النجاح حتى عند تكرار النسخ. الفهارس غير الصالحة والأدوار الأخرى لا تنسخ. كود الزر يمنع انتشار النقر والتصرف الافتراضي للتفاصيل؛ هذا ليس اختبار متصفح فعليًا.
- محاكاة HTTP للتنزيل تغطي404 وHTML وفشل الشبكة و429 و403 والرجوع إلى Contents API، وJSON غير الصالح، وتجاوز الحجم من الرأس أو البث، وفشل جميع المسارات. المضيفون موثوقون والمسارات لنفس رقم الإصدار، دون رابط عشوائي أو اختيار latest. الأدمن وحده يستطيع التنزيل؛ الرد ZIP بترميز Base64 واسم الإصدار، دون قاعدة أو أسرار.
- طابقت86 دالة تقارير وPDF وكل دوال التطبيق خارج6 دوال الإصلاح المحددة النسخة السابقة. الاستعادة والتشفير والمحركات و32 ملف SQL وملفات الربط محفوظة. CSS إضافات محددة للنسخ وهوية نموذج المجموعة، وroot/public متطابقان. جداول التجربة فيV3.8.0 وV3.8.1 تستخدم HTML باتجاه RTL ومحاذاة يمين صريحة.
- كود Updater V2.3.1 الفعلي قبل حزمة التشغيل ذات5 ملفات وأنتج public المطابق، دون كشف Worker كأصل عام، ومع حفظ الكرون والمتغيرات والربط. SOURCE يحفظ جميع مسارات وأصول الإصدار السابق؛ الاستثناء المقصود ملف تجاربV3.8.0 المطلوب تصحيح اتجاهه. أرشيفV3.8.0 نفسه لم يتغير.

الفحوص محلية ونماذج ببيانات مصطنعة، وليست قبولًا للشاشة أو سماعًا فعليًا أو تشغيلًا على Cloudflare. التحقق من روابط GitHub وهاش الحزم فحص تنزيل فقط؛ لا يثبت تحديث النشر على رابط التطبيق. لا متصفح أو Playwright أو صور شاشة أو SQL حي أو حذف أو استعادة أو إرسال خارجي. قبول الصوت والشاشات والموبايل والأونلاين للمستخدم. التصفير للدفعة التالية، وحالات الجرد القديم كما هي.
