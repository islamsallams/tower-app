# إصدار V3.8.3 — إشعارات الجهاز

ارتفع مستوى جرس الصفحة بنحو 4.8 ديسيبل مع نفس نغمتي «تين تان». اختيار الحساب أصبح «صفة» و«كل الصفات»، مع بقاء «الدور» للطوابق.

أضيفت بطاقة «إشعارات هذا الجهاز» في إعدادات التنبيهات ومركز الإشعارات، للتفعيل والتعطيل وتجربة الجهاز نفسه. التفعيل اختياري ويطلب إذن المتصفح عند الضغط فقط. إشعارات النظام تعرض عنوان الإشعار ونصه الأصليين، بما فيهما الأسماء والمبالغ، للحساب المستحق فقط. تنبيهات الطلبات تستخدم وصف فئتها الحالية؛ لا تُختلق مبالغ غير موجودة.

شغّل ملف SQL266 الجديد فقط، ثم ارفع ZIP تشغيل V3.8.3 وحدّث الصفحة بالكامل. على Android افتح التطبيق عبر HTTPS في Chrome، واضغط تفعيل إشعارات هذا الجهاز واسمح بالإشعارات. لا مفاتيح Push أو متغيرات Cloudflare إضافية مطلوبة.

صوت الصفحة مستقل عن صوت إشعارات Android. عند ظهور الصفحة لنفس الحساب يكون إشعار النظام صامتًا لتجنّب تكرار الصوت. خارج الصفحة يستخدم صوت نظام الهاتف، ويتأثر بإذن Chrome وقناة الإشعارات وعدم الإزعاج وإيقاف المتصفح إجباريًا وإعدادات البطارية. لا يمكن فرض جرس البيانو الخاص بالصفحة على إشعارات Android من الويب.

توجد محاولة إرسال بعد الإجراءات المناسبة، مع متابعة دورية كل خمس دقائق عند الحاجة. قبول مزوّد Push لا يثبت عرض الإشعار أو سماع صوته، والتسليم ليس مضمونًا في وقت محدد. قد تتكرر محاولة الرسالة بعد انقطاع غير محسوم؛ وسم الإشعار يقلل التكرار الظاهر.

التعطيل والخروج يلغيان ارتباط الحساب بهذا الجهاز. الاستعادة الفعلية تلغي اشتراكات أجهزة Push وتحتاج إعادة التفعيل، والبيانات التشغيلية للأجهزة مستبعدة من النسخة الاحتياطية. لا تتغير الحسابات أو التقارير وPDF أو مسار تنزيل الإصدار الحالي أو تشفير النسخ. التصفير التشغيلي ما زال دفعة تالية.

التحقق محلي بكود ونماذج معزولة فقط؛ لم تُرسل إشعارات فعلية، ولم يُشغّل SQL على القاعدة الحية أو يُنشر Cloudflare أو تُجر اختبارات متصفح وموبايل.
