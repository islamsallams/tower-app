# تحقق V3.8.3

نجحت 54 مجموعة فحوص محلية: 15 لقاعدة PostgreSQL معزولة، و8 لـWorker، و13 لنماذج الواجهة وService Worker، و1 لغلاف الصوت، و10 لحفظ النطاق، و7 للتوافق مع Updater V2.3.1.

تحققت مكتبة http_ece مستقلة من فك رسالة Web Push وفق RFC8291 والحفاظ على النص العربي والاسم والمبلغ، ومن رفض العبث. تحقق توقيع VAPID مستقل عبر Node crypto. اتصالات الإرسال في الفحوص بدائل محلية؛ لم يُرسل شيء لمزوّد حقيقي.

فحوص القاعدة تستخدم SQL263 وSQL265 وSQL266 الفعلية على PGlite بصفوف تجريبية وجداول دنيا مماثلة. تشمل عزل الحسابات وفقد العضوية والصلاحية والقراءة وحد الأجهزة والمهل وإلغاء الاشتراك واستعادة المعاينة والفعلية وإعادة تثبيت SQL266. لا تثبت تطابق كل تفاصيل قاعدة الإنتاج أو قبول تثبيته عليها.

اختبارات نماذج الكود والـDOM لا تستخدم متصفحًا أو صور شاشة، ولا تعتبر قبولًا بصريًا. قياس الصوت هو غلاف عددي لنغمة واحدة، وليس قياس سماعة أو سماعًا على جهاز. الزيادة 4.79 ديسيبل تقريبًا وغلاف النغمة 0.733 كحد أعلى، أقل من 1.

حُفظت 86 دالة تقرير وPDF في التطبيق كما هي. ملفات SQL السابقة الـ32 محفوظة بالبايت، وSQL266 وحده جديد. البنية التشغيلية الخاصة بـPush خارج نطاق النسخة العامة، مع RLS ومنع القراءة المباشرة، والمفاتيح الخاصة لا تصل للواجهة. الاستعادة تلغي ارتباط الأجهزة داخل المعاملة نفسها، والمعاينة تتراجع عنها.

لم يُنفّذ SQL حي أو نشر Cloudflare أو إرسال Push/Telegram فعلي. لا اختبار شاشة Android أو قفل الشاشة أو قبول أونلاين؛ هذه تجربة المستخدم. التصفير التشغيلي لم ينفذ، والتشفير محفوظ. تفاصيل النتائج في qa/v3.8.3 داخل SOURCE.
