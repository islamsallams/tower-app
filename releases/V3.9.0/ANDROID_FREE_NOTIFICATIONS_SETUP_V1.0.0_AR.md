# ربط إشعارات Android — تجهيز مجاني مرة واحدة

التطبيق نفسه يتثبت ويستخدم السيستم فورًا. الخطوات التالية لتفعيل إشعارات التطبيق الأصلية بالنغمة المرفقة. تتعمل مرة واحدة للإدارة، وليس لكل ساكن. لا تحتاج اشتراكًا مدفوعًا أو بطاقة دفع؛ لا تستخدم Cloud Functions أو أي خطة بفلوس.

## أولًا: تحديث السيستم

شغّل SQL269 الجديد فقط في Supabase، ثم ارفع ZIP تشغيل V3.9.0 بالـUpdater المعتاد. لا ترفعAPKللـUpdater؛ الـAPKيتثبت على الموبايل.

## ثانيًا: ملفان من Google

1. افتح [Firebase Console](https://console.firebase.google.com/) بحساب Google عادي واضغط إنشاء مشروع، مثل «Tower App». استخدم الخطة المجانية Spark. لا تحتاج Google Analytics لهذه الخطوة.
2. داخل المشروع، أضف تطبيق Android. في اسم الحزمة اكتب بالضبط: `com.islamsallams.towerapp`. الاسم الظاهر ممكن Tower App. بصمة التوقيع اختيارية لخدمة الإشعارات المستخدمة هنا.
3. نزّل ملف إعداد التطبيق الذي اسمه `google-services.json`. لا تحتاج إضافة كود Google أو إعادة بناءAPK؛ ربطه جاهز بالفعل.
4. من علامة الترس ← إعدادات المشروع ← حسابات الخدمة، اضغط إنشاء مفتاح خاص جديد ثم نزّل ملفJSONالثاني. ده ملف الربط الخاص؛ خليه على جهازك ولا تنشره أو تبعته في الشات.
5. من إعدادات المشروع ← Cloud Messaging، تأكد أن واجهة Cloud Messaging API الحديثة مفعّلة. تفعيلها لا يحتاج خطة مدفوعة. لو واجهة Google عندك مختلفة ابعت صورة الشاشة، من غير محتوى ملف المفتاح، ونكمل خطوة بخطوة.

## ثالثًا: الربط من الكمبيوتر

فك ضغط حزمة تجهيز الإشعارات. افتح `Connect-Free-Notifications.cmd` بضغطة مزدوجة. هيطلب منك تختار الملف الأول، ثم الملف الثاني. استخدم نفس الكمبيوتر وحساب Cloudflare المستخدمين مع Updater؛ قد يطلب تسجيل دخول Cloudflare في المتصفح لو انتهت جلسته.

البرنامج يقرأ الملفين، ويتأكد أنهما لنفس المشروع والتطبيق، ثم يحفظ الربط داخل Worker حسابك. لا يضع المفتاح الخاص داخلAPKأوSOURCEولا يطبع قيمته. يحتاج Node.js LTS المجاني، وهو نفس البرنامج الذي يستخدمه Updater.

لو ظهرت صفحة تطلب بطاقة دفع، لا تكملها؛ دي ليست خطوة مطلوبة للمسار المستخدم هنا. لا تفعّل خطة مدفوعة من أجل التطبيق.

## أخيرًا: الموبايل

افتح التطبيق وسجّل الدخول، ثم مركز الإشعارات ← إعدادات التنبيهات ← تفعيل إشعارات التطبيق. اسمح بالإذن، واضغط تجربة إشعار. بعد نجاحها اطلب مشوارًا من جهاز ساكن آخر وشاشة الأمين مقفولة.

صوت Android الافتراضي لهذا التطبيق هو تين تان، لكن الصامت وعدم الإزعاج وتعطيل الإشعارات وإعدادات البطارية تظل تحت تحكم الهاتف. GooglePlayservicesمطلوبة لـFCM. استقبال إشعار أو سماعه لم يُختبر فعليًا بواسطة المساعد؛ ننتظر تجربة هاتفك.

الإرسال يتم بعد الإجراءات المناسبة، مع متابعة دورية كل خمس دقائق عند الحاجة. قبول Google للإرسال ليس تأكيدًا أن الهاتف عرضه أو سمعه. حدود خدمات Cloudflare وSupabase المجانية الحالية تظل سارية؛ لا يُفعّل التطبيق دفعًا تلقائيًا.
