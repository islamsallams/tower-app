# إصدار V3.9.0 — ربط أول تطبيق Android V1.0.0

تطبيق Android موقّع ومبني فعليًا يفتح نفس السيستم ونفس الحسابات والبيانات، مع جلسة تطبيق مستقلة محفوظة بتشفير AndroidKeystoreدون حفظPIN. واجهات الموقع وتحديثاته المعتادة تُحمّل من نفس الرابط؛ تغييرات برنامج Android نفسه تحتاجAPKجديدًا بنفس مفتاح التوقيع وموافقة المستخدم على تثبيته. النشر والتوزيع مباشر ومجاني.

أضيف دعم Firebase Cloud Messaging المجاني لرسائل بيانات يعرضها التطبيق بإشعارات Android الأصلية ونغمة تين تان المرفقة. تفعيلها اختياري بعد ربط مشروع Google مرة واحدة، ولا تبدأ بمجرد تثبيتAPK. لا Cloud Functions أو منتجات مدفوعة أو بطاقة دفع، ولا حساب Google لكل ساكن. مفاتيح حساب خدمة Google داخل Worker فقط، ولا توضع فيAPKأوالمصدر أو الشات.

تسجيل الخروج أو تبديل الحساب يوقف ارتباط إشعاراته محليًا فورًا مع طلب إلغاء على الخادم. الردود المتأخرة لا تعيد ربط حساب انتهى دخوله أو ألغى التفعيل. لكل تثبيت سر مستقل، ولا يستطيع حساب آخر الاستيلاء عليه بدونه. قراءة المستخدم وصلاحياته الحالية وإصدار بيانات دخوله تُراجع قبل الإرسال؛ الاستعادة الفعلية تفصل الأجهزة الأصلية والجديدة ذريًا، والمعاينة تتراجع عن الفصل. بيانات الأجهزة والطابور في schemaخاص خارج النسخة العامة.

صيغة المشوار المعتمدة محفوظة: الاسم الأول لصاحب الطلب ولقبه ورقم الوحدة، والبنود ثم ملاحظة إن وجدت، بلا مسافة أو تصنيفها أو أتعابها أو إجمالياتها أو أسعار البنود. NativeFCMوWebPushيعتمدان نفس إسقاطSQL268للمحتوى، دون تغيير محرك المشاوير أو أسعارها أو التسويات أو الحسابات أو PDF.

واجهة Nativeداخل نفس بطاقة الإشعارات بهوية النظام. حفظ تقاريرPDFوتنزيلاتBlobيستخدم اختيار مكان الحفظ في Android، واختيار ملف يمر عبر نافذة الهاتف دون إذن تخزين عام. التطبيق لا يحمّل روابط خارج أصل السيستم داخل الواجهة المميزة؛ تفتح الروابط الخارجية الآمنة في المتصفح، والربط الأصلي مقصور على إطار الصفحة الرئيسي وأصلHTTPSالمعتمد. جلسات التطبيق لا تدخل نسخ Android السحابية أو النقل بين الأجهزة.

التثبيت: شغّل SQL269 الجديد فقط ثم ارفع ZIP التشغيل V3.9.0.APKV1.0.0 يتثبت على Android8+ مع WebViewحديث؛ الربط المجاني له دليل وملف اختيار للملفين من الكمبيوتر. لا نشرCloudflareأوSQLحي أو رسائلGoogleفعلية من المساعد.

تحتفظ خدمات السيستم بحدودها المجانية. دفعات الإرسال محدودة بأربعة لكل وسيلة لتوفير هامش لطلبات Workerالمجاني؛ حارس الطابورWebيدعم حدًا اختياريًا مع بقاء الافتراضي القديم12لبقية callers. المتابعة الدورية الحالية كل5دقائق دون تغيير موعدcronالأصلي. لا ضمان تسليم لحظي أو سماع الصوت، وإعداداتAndroidتظل مؤثرة.
