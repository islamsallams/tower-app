# تحقق V3.9.1 وAndroid V1.0.1

نجحت 67 مجموعة فحوص محلية، شاملة فحوص الحزم. شملت SQL الفعلي داخل PGlite بجداول ومستخدمين مصطنعين، ومسار الإرسال وقيود الوحدة في نموذج JavaScript/DOM، وربط أماكن38وحدة، ومسارات Worker مع منع الخروج إلى الشبكة، وعزل حساب APK وحفظ الملفات، وبناء APK والتوقيع وAndroid Lint.

- توقيع APK يطابق1.0.0؛ فحص Lint بلا أخطاء أو تحذيرات.
- كل86كتلة تقرير/PDF وكل دوال المشاوير والحارس والتسويات القديمة في الواجهة محفوظة حرفيًا.
- محررات أنواع الوحدات والحالات والتصنيفات محفوظة؛ لا أوزان جديدة في هذه الدفعة.
- ملفات SQL القديمة كما هي؛ SQL270وSQL272فقط للإنتاج، في ملف تثبيت واحد ومعاملة واحدة. SQL271تشخيص قراءة فقط وقد استلمنا نتيجته من المستخدم.
- لم يُنفذ SQL حي أو تصفير حي أو استعادة حية أو نشرCloudflare أو إرسالGoogle/Telegramفعلي.
- لا متصفح أو Playwright أو صور شاشات أو محاكي أو تثبيتAPKعلى جهاز من المساعد. نماذج DOM وفحوص الربط لا تثبت قبول الشاشة أو السماع أو وصول الإشعار.
- قبول الصورة ومواقع الإضاءة والسحب والشاشات والعمليات المنشورة ينتظر تجارب المستخدم.

ملف delivery-checks.json يلخص أعداد الفحوص وتطابق الحزم والبصمات. لم نعلن سبب بلاغ زر الاشتراك القديم كحقيقة؛ المسار الجديد اختُبر محليًا والاستخدام الفعلي للمستخدم.
