# إصدار V3.9.3 المجمّع للويب وAndroid

- معالج الترحيب بخمس شرائح للساكن: الاسم والاتصال، المظهر والخط، الإشعارات، إعدادات الوحدة المسموحة، والأمان أخيرًا. التعديل اختياري في كل شريحة. نفس أماكن الإعدادات الأصلية موجودة.
- الإعدادات داخل المعالج؛ الحفظ لا يخرج لصفحة الحساب. التنقل والنقط والسحب يحتفظون بالمسودة دون تطبيقها. تخطي يتجاهل مسودة الشريحة، ولاحقًا ينبه عند وجود تعديل غير محفوظ. PIN لا يُحفظ في التخزين المحلي، وتغييره بعد تأكيد ينهي المعالج ويسجل الخروج بمعاملة واحدة.
- الاسم واللقب بنفس المكون في الحساب والمعالج: اللقب فوق، والاسم الأول وباقي الاسم بنسبة1:2 ومعاينة فورية. بيانات العضويات منفصلة عن شاشة الاسم.
- نور وحدتك في كل الشرائح، والمساحة مرنة فوق المحتوى، مع أزرار ثابتة ومحتوى قابل للتمرير. إزالة هيدر المعالج القديم والعداد وزرX، واستبدال العداد بنقط قابلة للضغط وسحب أفقيRTL.
- خلفية جديدة شبابيكها مطفية مع وضوح العمارة والشارع والمدخل. طبقة الوحدة المنورة من المصدر الأصلي. كارت الرئيسية قابل للطي ويحفظ الاختيار لكل حساب. لا وميض مستمر مفروض.
- كارت تحديث Android كامل قابل للضغط ولوحة المفاتيح؛ نفس الفحص والتنبيه والتنزيل الآمن القائم. التطبيق والويب3.9.3 ورقم بناءAndroid4بنفس التوقيع.
- المشاوير المفتوحة6لكل صفحة، وفلتر للوحدة عند الأمين وللبنود غير المسعّرة بنفس النقطة الحمرا الموجودة. صفر سعر مسجل. الفلاتر لا تمس إجمالي الحساب أو بيانات التسوية، ولا تكشف المسافة أو الأتعاب للأمين.
- التصفير بهوية النظام، قوائم واضحة بلا تمرير داخلي، وخيارات حذف الخدمات والمهمات والوحدات وحسابات السكان، وحسابات الإدارة بخيار مستقل مع حفظ حساب المنفّذ.
- الاحتفاظ بالخدمات أو المهمات يعني الاحتفاظ بالتعريف فقط؛ كل الاشتراكات والمستحقات والسداد ومشاركة المهمات القديمة تُصفّر دائمًا حتى مع الاحتفاظ بالأشخاص. حذف الأشخاص يحذف عضوياتهم وجلساتهم وإعداداتهم المرتبطة. سجل العمليات محفوظ مع فك الارتباط بالحساب المحذوف.
- إذا حُذف مستفيد خدمة شخصية واحتُفظ بالخدمة: الحساب القديم يُصفّر ويُحذف، وتعريف الخدمة يظل شخصيًا وموقوفًا. تظهر للإدارة أداة تعيين مستفيد جديد بحساب فارغ؛ التفعيل بعدها يدوي. لا تحويل تلقائي للصندوق ولا إعادة مشتركين قدامى.
- المعاينة مربوطة بالبيانات الفعلية والاختيارات. تغييرها يلغي التأكيد. كل التنفيذ معاملة واحدة؛ خطأ أو ارتباط غير معتمد يرجّع العملية كلها. تثبيتSQLوفتح المعاينة لا يحذفان بيانات.

لم تُشغّل قاعدة البيانات الحية أوCloudflare أو المتصفح أو المحاكي أو اختبار هاتف، ولم تُرسل إشعارات حقيقية. اختبارات الكود وSQL المحلية وبناءAPK والتوقيع فقط. قبول الشكل والمحاذاة والسحب وسلوك Android للمستخدم.

أوزان التحصيل والتصنيفات وتأثير الأنواع والحالات ما زالت مؤجلة للنقاش.
