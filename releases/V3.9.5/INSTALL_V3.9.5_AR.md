# تثبيت V3.9.5 فوق V3.9.4

1. شغّل [SQL276 فقط](https://github.com/islamsallams/tower-app/raw/main/releases/V3.9.5/SQL276_FUNDING_AND_TELEGRAM.sql) كاملًا في SQL Editor داخل Supabase. يعتمد على SQL274 المثبت عندك. التثبيت يحدّث الإجراءات ولا يمول مهمة أو يحسم طلب عضوية أو يرسل سجلات قديمة.
2. ارفع [حزمة تشغيل V3.9.5](https://github.com/islamsallams/tower-app/raw/main/releases/V3.9.5/Tower_App_V3.9.5.zip) بالـUpdater المعتاد، ثم حدّث الصفحة.
3. على Android استخدم زر تحديث التطبيق بعد رفع الويب، أو [APK3.9.5](https://github.com/islamsallams/tower-app/raw/main/android-releases/V3.9.5/Tower_Android_V3.9.5.apk). يثبت فوق القديم دون حذفه وبنفس التوقيع.
4. نفّذ [التجارب المختصرة للتعديلات](https://github.com/islamsallams/tower-app/raw/main/releases/V3.9.5/USER_ONLINE_TEST_V3.9.5_AR.md).

نسخة [SOURCE الكاملة](https://github.com/islamsallams/tower-app/raw/main/releases/V3.9.5/Tower_App_V3.9.5-SOURCE.zip) مستقلة عن حزمة التشغيل ذات5ملفات. الربط الحالي بتليجرام مستمر؛ لا تفعله مجددًا لمجرد التحديث. الرسائل تنتظر طابور الإرسال المجدول المعتاد وليست وعدًا بوصول فوري.

رسالة تمويل قديمة ظلت عامة لن تتغير بأثر رجعي؛ افتح المعاينة بعد التثبيت لعرض النتيجة أو رسالة الخطأ الجديدة. رفض الطلبات المعلقة يجرب بعد التحديث؛ لا يتم رفضها تلقائيًا بالتثبيت.
