# تصحيح بدء التطبيق V3.9.6

إصدار395 أدخل استدعاءً عند بدء التطبيق لقراءة رابط Telegram حتى مع عدم وجود رابط. إعدادات الرفع تضيف const URL كنص اتصال؛ الاستدعاء الجديد استخدم new URL فتعارض مع الاسم، ووقع بدء التطبيق بعد التحقق من الدخول. الواجهة المنشورة فُحصت للقراءة فقط وتطابقت مع395 بعد مقدمة إعدادات الرفع. لم تستخدم بيانات دخول حقيقية في التشخيص.

التصحيح يستخدم globalThis.URL داخل الخطاف الجديد؛ لا يغير المصادقة أو البيانات أو صلاحيات الروابط. نسخ تفاصيل الخطأ يحدد مرحلة التحقق أو تحميل الحساب أو بدء التطبيق، ويذكر نوع الخطأ البرمجي وسببه المعروف الآمن، حتى لا يتصنف عطل بدء الواجهة كفشل بيانات الدخول بلا تفاصيل.

لاSQLجديد. كل SQL وCSS وحسابات المشاوير والتسويات والمهمات ورسائلTelegram كما في395. يمكن تحديث الويب لإصلاح واجهة المتصفح والموبايل الحالية؛ APK396 متاح بنفس التوقيع ورقم داخلي7 لتوحيد الإصدار.
