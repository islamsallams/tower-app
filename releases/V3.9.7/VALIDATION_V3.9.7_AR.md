# تحقق V3.9.7

نجحت الفحوص المحلية التالية من المصدر الحالي، بلا متصفح أو بيانات حقيقية:

- بدء التطبيق والدخول مع مقدمة Updater التي تعرّف `const URL`، وروابط Telegram، وعدم تعطيل الدخول عند تعذر مصدر الأدعية الاختياري.
- نماذج DOM وحالة تشغّل الدوال الفعلية: عرض الأرصدة المسجلة، وفصل المساهمة عن استلامها، وعدم تحويل البيانات المجهولة إلى صفر، وصفوف الوحدات، وفصل التمويل عن التنفيذ دون تكرار IDs، والنوافذ والتنقل أثناء الحفظ، وخطوات الإدخال والمراجعة دون حفظ مبكر.
- اختيار الأدعية: ثباتها لنفس الجلسة بعد إعادة التحميل، وتجنب آخر دعاء مع وجود بديل، والتعامل مع القائمة الفارغة أو دعاء واحد، وعزل الحسابات والردود المتأخرة، وعدم تخزين PIN أو token إضافي.
- PostgreSQL عبر PGlite: تثبيت ملف SQL277_278 المجمّع وإعادته دون إرسال قرارات قديمة، وإشعار رفض موجّه لصاحب الطلب في نفس المعاملة، وعدم استخدام ملاحظة الطلب الأصلية كسبب رفض. إدارة الأدعية تشمل الصلاحيات والتعديل والحذف والتفعيل وحماية المراجعة من التعديل المتزامن.
- Worker مع اعتراض كل HTTP: الصلاحيات ورسائل Telegram والخصوصية، وفهرس فلترة الوحدات بما يتجاوز حد PostgREST البالغ 1000 صف، ومنع الاتحاد والساكن من إدارة الأدعية.
- مقارنة الدوال بمحلل Acorn مقابل مصدر396: كل الدوال القديمة خارج قائمة تغييرات الواجهة والتحميل متطابقة بايت ببايت. حفظ إعدادات المهمة يتغير في تبويب الرجوع فقط، دون تغيير الحمولة أو التحقق. موجه Worker يضيف مسارين مقيدين فقط. المصادقة والمالية والمشاوير والتسويات وPDF والنسخ والاستعادة والتصفير محفوظة. ملفات SQL القديمة لم تتغير، والـCSS القديم محفوظ بالكامل قبل مجموعة الأنماط الجديدة.
- الفحوص السابقة للتمويل والتقريب والرصيد والائتمان والاستلام والذرية وإعادة التنفيذ وTelegram، والتسويات ومدفوع الاعتماد والتراجع والخدمات الدورية والتصفير الاختياري.
- Android: بناء وتوقيع وLint، وسياسة التحديث على JVM، ونموذج الربط الأصلي، وشهادة APK ورقمه ومحتوياته وعدم وجود أسرار.
- الحزم: CRC، وتطابق التشغيل والمصدر وpublic، وحفظ مسارات المصدر السابق، واستبعاد الأسرار والتوقيع والـSDK، ثم مطابقة بصمات ملفات GitHub بعد الرفع.

لتشغيل البوابة من المصدر: ثبّت اعتماديات الاختبار المجانية مرة واحدة بالأمر `npm install --prefix tools/regression`، ثم `python3 tools/check_release397.py`. يمكن تحديد مسارات المكتبات بمتغيرات TOWER_PGLITE_MODULE وTOWER_DOM_MODULE وTOWER_ACORN_MODULE. تعمل الحالات بأربعة مسارات متوازية، وأي فشل يمنع اعتماد الحزم. النتائج في qa/v3.9.7، والسجلات الخام في مجلد مؤقت خارج الحزم. فحص المقارنة يحتاج SOURCE396 كمرجع، ويمكن تحديد مساره بـTOWER_PREVIOUS_SOURCE.

الفحص البصري والمتصفح والمحاكي والهاتف ووصول الإشعار الفعلي لم تُنفذ، بتوجيه المستخدم. تقرير التصميم في docs/design/V3.9.7/design-qa.md يسجل التحقق البصري كمعلّق. الصورة المرجعية تصميم معتمد وليست لقطة للبرنامج المنفذ؛ لا ادعاء بمطابقة بكسلية أو قبول إنتاجي.

امتداد حماية التحديثات الخاص بـSupabase غير متاح داخل PGlite؛ لم يُعطّل، وتصحيح شرط WHERE المثبت في276 لم يتغير. لم ينفذ المساعد نشر Cloudflare أو SQL حيًا أو رسائل حقيقية.
