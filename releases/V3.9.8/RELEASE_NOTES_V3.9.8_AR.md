# إصدار V3.9.8

إصلاح رابط تنزيلAPK، وتوضيح الرجوع وإجراءات المهمات، وإظهار إنجاز الأعمال. مسؤول حساب المهمة الفعلي يؤكد استلام التمويل؛ الدور الإداري وحده لا يسمح بالاستلام نيابة عنه. تمويل الصندوق واعتماده مستقلان عن تأكيد الاستلام.

حفظ المهمة يرسل الحقول المعدلة فقط بعد مراجعة النسخة الحالية؛ التعارض يعرض الحقل وقيمته الحالية واختيارك، ويحتفظ بمدخلاتك دون حفظ تلقائي. تحصيل المهمة «كامل / جزئي / بمقدم إضافي»، ومسميات المصروف تفرق بين تسجيله للمراجعة وتأكيد دفعه من العهدة.

التسوية تفحص الأسعار أولًا. المشاوير الناقصة تعرض اختيار استثنائها بالكامل بأتعابها أو فتحها لإكمال الأسعار؛ كلّها ناقصة يعني لا تسوية فارغة. الصفر سعر مسجل. المدفوع الآن والأتعاب الإضافية والرصيد المرحّل والتراجع كما هي. لا تغيير للتسويات القديمة أو لتنسيق بنود الكشف.

يوم المشوار يظهر مع تاريخه بتوقيت القاهرة، مثل «الأربعاء 4/11/2026». هيدر كشف التسوية ولوجوه أوضح. رأس مركز الإشعارات مضغوط وثابت أثناء التمرير و«تحديد الكل كمقروء» مباشر. مبالغ ملخص الأمين وعملتها بمحاذاة اليمين.

الملف الجديد SQL279_280 مطلوب، ولا يعمل تلقائيًا برفعZIP. واجهة الويب والموبايل3.9.8، والـAPKرقم داخلي9 وبنفس التوقيع. الفحوص الآلية محلية؛ لم ينفذ SQL حي أو نشر Cloudflare أو اختبار متصفح/هاتف أو إرسال إشعارات حقيقية. المراجعة البصرية للمستخدم.
